## 1. 게임 소개

3D 플랫포머 + TPS / PC · 싱글플레이 / 4명

스마트폰 속 앱 세계를 탐험하며, 여러 능력과 이동수단, 데이터 무기로 에피소드를 해결하고 이야기를 진행하는 3D 플랫포머.

### 핵심 게임 시스템

- **스캔**: 스마트폰 내부 데이터를 스캔해 숨겨진 정보, 적의 약점, 퍼즐 단서를 찾는다.
- **배터리로 관리하는 스킬**: 블루투스, 스캔 같은 능력이 배터리 자원 하나를 함께 쓴다. 상황에 맞는 자원 관리가 중요하다.
- **상호작용 2종류**: 직접 다가가 쓰는 근거리 상호작용, 데이터 패킷을 쏴서 작동시키는 원거리 상호작용.
- **퍼즐 · 미로 · TPS**: 스테이지마다 하나의 성격을 갖고, 마지막 보스 맵에서는 세 요소가 모두 합쳐진다.

### K-Culture 요소

- 폰 주인은 K-POP 가수 지망생이다. 메인 스토리가 K-POP을 중심으로 흘러간다.
- K-POP, K-Culture 소식을 피드와 팝업으로 중간중간 계속 노출한다.
- 폰 주인의 알고리즘이 K-Culture로 채워져 있다.

### 파트 분배

| 담당 | 파트 | 범위 |
| --- | --- | --- |
| 양준범 | 맵 / 레벨 | 맵 배치, 씬 전환 |
| 이세훈 | 플레이어 / 전투 | 플레이어 이동, 전투, 탈것 |

## 2. 플레이어

이동 · 전투 · 탈것

### 키 세팅

| 동작 | 키 | 비고 |
| --- | --- | --- |
| 이동 | W A S D |  |
| 점프, 이단점프 | Space | 이단점프는 배터리를 쓰지 않는다 |
| 구르기 | Left Shift |  |
| 차지샷 | 마우스 우클릭 유지 | 누르고 있으면 충전과 발사를 자동으로 반복한다 |
| 일반 사격 | 마우스 좌클릭 | 꾹 누르면 일반 총알이 계속 나간다 |
| 상호작용 | E | 근거리 |
| 스캔 | Q |  |
| 블루투스 이동 | F |  |
| 일시 정지 | ESC |  |
| ~~와이파이 이동~~ | ~~지점에서 E~~ | 삭제 |

캐릭터는 기본으로 총을 들고 있다. 원거리에서도 데이터 패킷으로 상호작용을 하기 위해서다.

### 총기 시스템

- 탄약 대신 과열 게이지를 쓴다.
- 사격할수록 과열 게이지가 오른다. 차지샷은 일반 총알보다 과열 게이지가 더 빠르게 오른다.
- 최대치에 닿으면 일정 시간 사격할 수 없다.
- 사격을 멈추면 게이지가 자동으로 내려간다.
- 무한 사격을 막고 사격 타이밍과 자원 관리를 유도한다.

### 차지샷 · 충전과 발사

- 오른쪽 마우스를 꾹 누르면 충전한다. 계속 누르고 있으면 차지샷의 충전 → 발사를 자동으로 반복한다.
- 발사 판정 시 충전 게이지가 정해진 기준선을 넘으면 차지샷, 넘지 못하면 일반 총알이 나간다.
- 충전 게이지는 발사 종류를 결정하고, 과열 게이지는 사격 가능 여부를 결정한다.
- 과열 최대치에서는 차지샷을 포함해 일정 시간 사격할 수 없다.

- **기준선 미달**: 일반 총알 발사
- **기준선 초과**: 차지샷 발사 · 과열 상승이 더 빠름

충전 기준값·충전 시간·반복 간격·발사 판정 시점(버튼을 놓을 때의 처리 포함)은 미정.

### 배터리(마나)

| 스킬 | 소모 |
| --- | --- |
| 구르기 | 사용 시 일정량 |
| 블루투스 이동 | 사용하는 동안 계속 |
| 스캔 | 사용 시 일정량 |

- 배터리는 시간이 지나도 자동으로 차지 않는다. 충전 아이템과 로비에서 회복한다.
- 모든 스테이지는 배터리를 쓰지 않아도 클리어할 수 있게 만든다.
- 배터리를 쓰면 이동, 전투, 탐색 난이도가 내려간다.

### 상호작용

- 근거리: 오브젝트에 다가가 E로 직접 조작. 버튼, NPC 대화, 문 열기, 데이터 단말기.
- 원거리: 오브젝트를 총으로 쏴서 작동. 원거리 스위치, 플랫폼 기믹, 퍼즐 장치, 접근하기 어려운 장치.
- 화면에서 색과 외곽선으로 두 방식을 구분한다. 상호작용 가능한 아이템에 스캔이 닿으면 실루엣이 보인다.

### 블루투스 (이동수단)

| 동작 | 키 |
| --- | --- |
| 자동 전진 | W를 누르지 않아도 앞으로 계속 이동 |
| 점프 / 더블점프 | Space |
| 마지막 요시점프 | 가능 · 세부 입력과 동작은 미정 |
| 차지샷 / 일반 사격 | 우클릭 유지 / 좌클릭 |

- 탑승 중 이동속도와 점프속도가 기본 상태보다 빨라진다.
- 더블점프가 가능하고, 마지막에 요시점프를 사용할 수 있다.
- 자동 전진 중에도 점프를 조작하며 이동한다.
- 사용하는 동안 배터리를 계속 소모한다.

이동속도·점프속도의 증가량, 방향 전환·감속 조작, 요시점프의 발동 조건과 탑승 해제 여부는 미정.

### 인게임 화면에 둘 것

- 체력
- 과열 게이지
- 차지샷 충전 게이지와 발사 기준선
- 전체 배터리 게이지
- 조준점

UI 위치는 나중에 의견을 모아 정한다. 구르기, 블루투스, 스캔을 지금 쓸 수 있는지 보여 주는 표시는 고민 중이다.

### 플레이어 수치

| 값 | 수치 | 값 | 수치 |
| --- | --- | --- | --- |
| MaxHP | 100 | MaxBattery | 100 |
| AttackDamage | 10 | RollBatteryCost | 1 |
| InvincibleTime | 1초 | ScanBatteryCost | 15 |
| MaxHeat | 100 | BluetoothBatteryCost | 초당 1 |
| HeatPerShot (일반) | 10 | HeatRecoveryRate | 초당 5 |
| FireIntervalRate (일반) | 0.2초 (좌클릭 유지 시 일반 사격 간격) | MoveSpeed · JumpPower | 미정 |
| BulletRange | 미정 | InteractionRange | 미정 |

### 미정

- 블루투스 탈것의 형태. 기획서에 두 안이 있고 “둘 중 하나로” 정하기로 되어 있다.
- 블루투스를 탔을 때 이동 권한을 탈것으로 넘길지.
- 블루투스 이동·점프속도 증가량, 방향 전환·감속 조작, 요시점프의 세부 동작.
- 차지샷 기준값·충전 시간·반복 간격·피해량·과열 증가량과 발사 판정 시점.
- 우클릭 차지샷과 기존 조준 동작의 병행 여부, 좌우 클릭 동시 입력 처리.

## 3. AI

적 · NPC

### 로비 NPC · 인도를 걷는 사람

- 플레이어가 앞에 있으면 멈춘다.
- 뒤에 대열이 있으면 같이 멈춘다.
- 대화나 상호작용은 하지 않는다.
- 다른 행동을 하는 NPC는 필요하면 추가한다.

### 로비 NPC · 자동차

- 공중에서 플랫폼처럼 움직이는 자동차가 있다.
- 플레이어가 앞에 있으면 멈춘다.
- 바닥은 차도와 인도가 나뉘고, 차는 차도로만, 사람은 인도로만 다닌다.
- 두 NPC 모두 충돌 처리를 한다.

### 적 시스템

- 날아다니는 적은 만들지 않는다.
- 일반 몹(근거리, 원거리)은 보안 앱에서 나온다.
- 적에게 스캔이 닿으면 약점 부위가 생기고 체력이 보인다. 약점은 몬스터마다 다르고, 맞히면 치명상을 입힌다.
- 보안 앱 3라운드에 이동형 보스와 고정형 보스, 총 2명이 나온다. 각 보스는 고유 패턴을 가진다. 이동형 보스를 먼저 2번 그로기시켜야 고정형 보스에게 피해를 줄 수 있다.
- 적 AI를 고려해 과한 점프 위주의 플랫폼 구성은 피한다.

### 파일 앱 3라운드의 도망자

- 미로에서 플레이어를 피해 도망다니는 역할만 한다.
- 공격하지 않는다.

### 적 종류

- **근접**: 이동이 빠르지만 공격 범위가 짧다. 일정 거리 안에서 공격한다.
- **원거리**: 플레이어가 다가오면 물러나거나 자리를 바꾼다. 플레이어 위치를 기준으로 투사체를 쏜다.
- **특수**: 체력이 아주 많고 스캔해서 약점을 노려야 하는 적. 구상 단계.
- **보스 2명**: 움직이는 이동형 + 가만히 있는 고정형. 이동형의 그로기 2회를 먼저 달성하면 고정형 공격이 가능해진다. 각 보스의 구체적인 패턴은 미정.

### 미정

- 적 수치 전부: MaxHP, MoveSpeed, AttackDamage, AttackRange, AttackCooldown, AttackInterval(원거리 몬스터가 한 번에 1~3발을 쏠 때 발 사이 간격).
- 드랍 보상(배터리 충전, 체력 회복)을 넣을지.
- 적의 외형(근접은 강아지형, 원거리는 인간형 안).

## 4. 시스템

스캔 · 상호작용 · 연출 · UI

### 스캔 시스템 · 대상에 닿았을 때

Q로 스캔을 사용한다. 스캔이 닿은 대상의 종류에 따라 아래 효과가 나타난다.

| 대상 | 스캔 접촉 효과 |
| --- | --- |
| 적 | 약점 부위가 생긴다. 약점을 맞히면 치명타가 들어간다. |
| 피드맵의 숨겨진 플랫폼 | 평소 보이지 않다가 스캔이 닿으면 플랫폼이 보인다. |
| 미로맵의 벽 뒤 아이템 | 스캔이 닿으면 벽 너머에서도 아이템의 실루엣과 위치가 보인다. |
| 상호작용 가능한 아이템 | 스캔이 닿으면 실루엣이 보인다. |

- 글자나 색으로 오브젝트를 구별해 준다.
- 범위와 지속시간이 있고, 지속시간 동안에만 기능이 켜진다.

### 상호작용 표시

- 근거리, 원거리 상호작용이 되는 물체에 기본으로 서로 다른 색을 준다.
- 스캔이 닿은 상호작용 아이템은 실루엣으로 드러나며, 근거리·원거리 구분도 더 두드러진다.
- 근거리: NPC 대화, 아이템 획득, 데이터 삽입.
- 원거리: 접근하기 어렵거나 전투, 플랫폼 이동 중에 빠르게 작동해야 하는 장치.
- 작동에 성공하면 효과음과 이펙트로 알려 준다.

### 연출 장면

1. 폰 주인이 폰을 들고 가다 떨어뜨리는 장면.
2. 인스타에 올라간 피드를 폰 주인이 보고, 이 노래를 만들어야겠다고 다짐하는 장면.
3. 완성한 곡을 직접 업로드하고 곡이 유명해지는 장면.
4. 공연 요청을 받고 무대에 서기 전에 고민하는 장면.
5. 마지막 무대 장면.

### 그 밖의 시스템

- 스테이지마다 목표 UI를 띄워 방향을 잡아 준다.
- 필요하면 플레이어의 독백을 대사로 띄운다.
- 세이브와 진행도 시스템은 넣을 수 있으면 넣는다.
- 맵 답변으로 시스템 파트에 넘어온 것: 체크포인트, 아이템, 인스타 Stage 구분과 피드 완성 표현, 파일 앱 NPC 대결 판정, 스캔으로 숫자 노드와 적 위치 표시, 로비 음악 앱의 배경음 변경.

### 미정

- 다음에 어느 스테이지로 가야 하는지 알려 줄지.
- 스캔 범위·지속시간과 벽 너머 표시 방식의 세부 수치.

## 5. 동선 · 공통 규칙

모든 맵은 3D 플랫폼 형태

### 스테이지 진행 순서

튜토리얼 → 로비(첫 도착) → 피드(인스타) → 로비(회복) → 파일(미로) → 로비(회복) → 보안(전투) → 로비(라이브 점등 컷신) → 라이브(엔딩)

로비는 스테이지 사이마다 돌아오는 허브다.

기능을 먼저 만들고 꾸미는 것은 나중에 한다.

- **클리어 조건**: 스테이지마다 다르게 만든다. 기획서의 클리어 게이지는 삭제.
- **체력 0**: 해당 스테이지를 처음부터 다시 시작한다.
- **바닥으로 추락**: 체력을 일정량 깎고 체크포인트로 이동한다.
- **회복**: 로비에서 체력과 배터리를 채운다. 스테이지 안에 체력·배터리 회복 아이템을 둘 수 있다.
- **와이파이 이동**: 삭제. 이동 스킬은 구르기와 블루투스만 남는다.
- **맵 파트 범위**: 맵 배치와 씬 전환까지. 판정, 아이템, 스캔 표시는 시스템 파트.

## 6. 튜토리얼

데이터 소각장 / 연속된 맵 1개 / 전투 없음

### 진행 순서와 배우는 조작

1. 발판을 타고 이동 — 이동 · 점프
2. 멈춘 발판을 쏴서 다시 움직이기 — 원거리 상호작용 · 추가됨
3. 노래 파일을 쏴서 재생 시도, 비밀번호로 잠겨 있음 — 원거리 상호작용
4. 되돌아가 비밀번호 찾기 — 근거리 상호작용 (E)
5. 잠금 해제, 재생, 노래 파일 획득 — 근거리 + 원거리
6. 보이지 않는 플랫폼을 찾아 건너기 — 스캔 (Q)
7. 떨어지는 것을 굴러서 피하기 — 구르기 (Shift)
8. 뒤에서 무너지는 구간을 타고 탈출 — 블루투스 (F) · 자동 전진 / 더블점프 / 요시점프

마지막 구간은 컷신이 아니라 직접 조작하는 추격 구간이다. 블루투스의 자동 전진, 빨라진 이동·점프, 더블점프와 마지막 요시점프를 배우는 자리다.

### 스토리

폰 주인이 길에서 휴대폰을 떨어뜨린다. 충격으로 생긴 오류 데이터가 플레이어다. 어디선가 들리는 노랫소리를 따라가 잠긴 파일을 열자 제목이 보인다. “이번에도 떨어지면 이제 그만해야 할지도 모르겠다.” 플레이어는 이 노래를 더 못 듣게 되는 것이 싫어서 파일을 들고 소각장을 빠져나온다.

### 맵 구성

- 구간을 나누지 않고 하나로 이어진 맵.
- 도입부(폰 낙하, 오류 메시지, 캐릭터가 일어남)는 별도 컷신.
- 탈출 지점이 로비의 시작 위치로 이어진다.

## 7. 로비

허브 / 기존 로비 씬을 이어서 사용

### 로비 배치 약도 설명

아래 위치는 원본 스케치의 예시이며, 확정된 좌표가 아니다.

| 구분 | 앱 / 지점 | 배치 예시와 역할 |
| --- | --- | --- |
| 입구 1 | 피드(인스타) | 왼쪽 아래 옥상 |
| 입구 2 | 파일 | 오른쪽 위 |
| 입구 3 | 보안 | 왼쪽 위 구석 |
| 입구 4 | 라이브 | 중앙, 엔딩 진입 |
| 상호작용 앱 | 캘린더 | 왼쪽 위 중앙 부근 |
| 상호작용 앱 | 날씨 | 왼쪽 위 외곽 |
| 상호작용 앱 | 음악 | 오른쪽 아래 |
| 시작 위치 | 튜토리얼 탈출 지점 | 아래쪽 중앙 |

중앙의 가로·세로 길을 중심으로 앱들이 배치된다.

원본 도식 설명: 색이 채워진 곳은 스테이지 입구, 점선은 상호작용만 되는 앱. 위치는 기획서 스케치를 따른 예시이고 입구 위치는 앱마다 다르게 잡는다.

### 스토리

소각장을 빠져나온 플레이어가 처음 보는 스마트폰 속 도시다. 폰 주인의 취향을 따라 도시의 전광판과 알고리즘은 K-POP, K-Culture로 채워져 있다. 스테이지를 하나 끝낼 때마다 여기로 돌아와 숨을 고른다.

### 맵 구성

- 스테이지 입구 4곳: 인스타, 파일, 보안, 라이브. 입장 순서는 고정.
- 상호작용 앱 3곳: 캘린더, 날씨, 음악. 기획서의 “위젯 플랫폼”은 이 세 앱으로 대체한다.
- 옥상으로 올라가는 발판은 여러 종류의 플랫폼 프리팹으로 따로 만든다.
- 전광판이 있다. 사람과 차가 지나다닌다.
- 체력과 배터리를 채우는 장소.

### 다른 파트 담당

- 시스템: 음악 앱의 배경음 변경.
- AI: 인도의 사람 NPC, 차도의 자동차 NPC.

### 미정

- 아직 갈 수 없는 앱을 막는 방법 (나중에 추가).
- 하늘의 데이터 조각과 랜덤 도움말은 이번 기획에서 뺀다.

## 8. 피드 (인스타)

플랫폼 + 퍼즐 / 전면 수정 / 2 Stage

### 스테이지 단면 설명

1. 아래에서 시작해 기둥을 감싼 회오리 플랫폼을 오른다.
2. 오르는 길에 미끼 피드와 피드 재료가 놓인다. 제목·사진·음악·내용·해시태그의 배치 순서는 예시다.
3. 플랫폼 주위에는 일반 피드 6개가 떠다닌다.
4. 꼭대기의 2 Stage에서 일반 피드 6개와 플레이어 피드 1개, 총 7개를 쏴서 해시태그로 보낸다.

원본 도식 설명: ■ 미끼 피드 5개(길을 막음) · ○ 피드 재료 아이템 5종 · 흰 카드는 주위를 떠다니는 일반 피드 6개. 아이템 순서는 예시다.

### 스토리

플레이어가 튜토리얼에서 가져온 데모곡을 폰 주인 몰래 인스타에 올린다. 피드를 손봐서 노래를 알린다. 폰 주인은 “내가 언제 이걸 올렸지” 싶지만 반응이 예상보다 좋아 게시물을 남겨 두고, 노래를 계속 만들어 볼까 하며 다시 작업을 시작한다.

### 1 Stage · 오르면서 피드 만들기

- 기둥을 감싸는 회오리 형태 플랫폼을 올라 기둥 꼭대기에 도착한다.
- 오르는 길에 제목, 사진, 음악, 내용, 해시태그를 하나씩 얻어 플레이어 피드를 완성한다.
- 피드는 모두 11개다. 일반 피드 6개, 악성 미끼 피드 5개.
- 미끼 피드가 아이템 앞을 막고 있다. 제거해야 아이템을 얻는다.
- 일반 피드는 플랫폼 주위를 떠다닌다.
- 평소 보이지 않는 플랫폼은 스캔이 닿으면 드러난다.

### 2 Stage · 올바른 해시태그로 보내기

- 완성한 플레이어 피드와 일반 피드 6개, 합쳐 7개로 시작한다.
- 각 피드를 총으로 쏴서 정해진 위치의 해시태그 안으로 날려 보낸다.

### 미끼 피드 제거 방식

| 번호 | 방식 |
| --- | --- |
| 1 | 상호작용 |
| 2 | 풍선에 매달린 악성 피드 |
| 3 | 스타포스 |
| 4 · 5 | 나중에 결정 |

### 담당

- 맵: 악성 피드, 플레이어를 쫓아오는 악성 데이터(발판을 무시하고 추적), 2 Stage 진입 때 일반 피드 이동.
- 시스템: Stage 구분, 체크포인트, 아이템, 피드 완성 표현, 스캔 접촉 시 숨겨진 플랫폼 표시.

### 미정

- 미끼 피드를 제거하면 악성 데이터 조각이 날아오는 것은 나중에 추가.
- 제거 방식 4번, 5번.

## 9. 파일 (미로)

미로 + 퍼즐 / 씬 1개 · 미로 3개

### 미로 연결 구조

1라운드(미로 탈출·함정) → 다리 → 2라운드(숫자 퍼즐·음악 파일 보관 영역) → 다리 → 3라운드(경찰과 도둑)

세 미로를 한 씬에 동적으로 생성하고 다리로 잇는다. 2, 3라운드 미로는 나중에 층(계단)을 나눠 단계별로 어렵게 만든다. 원본 보드의 미로 그림은 구조를 보여 주기 위한 예시다.

### 스토리

피드 반응을 본 폰 주인이 곡을 완성하려 한다. 플레이어는 복잡한 폴더 구조 속에서 예전 가사 메모, 멜로디 녹음, 코드 진행 메모, 흩어진 데모 파일을 찾아 건넨다. 3라운드에서 자료를 훔쳐 달아나는 작은 바이러스는 다음 스테이지에서 벌어질 대규모 감염의 전조다.

### 1 라운드 · 미로 탈출

- 함정을 여러 종류 쓴다: 위에서 떨어지는 장애물, 돌면서 방해하는 장애물, 사라졌다가 다시 나타나는 발판 등.

### 2 라운드 · 숫자 퍼즐

- 이 미로가 음악 관련 파일 보관 영역이다. 파일 관리자 NPC가 음악 파일을 지키고 있고, 검증 대결을 통과해야 얻는다.
- 연산자 노드(+, -, /, \*)와 피연산자 노드(1~9)를 미로에 랜덤 배치한다.
- 연산자 2개와 피연산자 3개를 모아 출구의 NPC와 대결한다. 내 식의 값이 더 높은 쪽이 이기는 방식과 더 낮은 쪽이 이기는 방식 중 하나가 정해진다.
- NPC는 연산자 4개 중 2개, 내가 먹지 않은 피연산자 중 3개를 랜덤으로 뽑아 가장 좋은 값을 낸다.
- 가비지 컬렉터는 없앤다. 대신 정해진 시간 안에 노드를 모아야 한다.

### 3 라운드 · 경찰과 도둑

- 도망다니는 바이러스를 제한 시간 안에 모두 잡아 음악 자료를 되찾는다. 바이러스는 공격하지 않는다.

### 다른 파트 담당

- 시스템: 스캔이 닿은 벽 뒤 아이템을 벽 너머에서도 실루엣으로 표시. 숫자 노드와 3라운드 적 위치 표시, NPC 대결 방식과 판정.
- AI: 도망다니는 바이러스.

## 10. 보안 (전투)

3라운드 / 일반 전투 → 진입 구간 → 보스 2명

### 라운드 진행 도식

```text
1라운드: 일반 몹 전투
    ↓
2라운드: 장애물 + 약간의 플랫포머 + 일반 적
    ↓
3라운드: 이동형 보스 + 고정형 보스
    ↓
이동형 보스 그로기 1회 → 그로기 2회
    ↓
고정형 보스 공격 가능
```

이동형 보스는 움직이며 고유 패턴을 사용한다. 고정형 보스는 제자리에서 고유 패턴을 사용한다.

원본 도식 설명: 3라운드의 진행과 보스 공격 조건을 보여 주는 개념도. 실제 지형 배치와 보스별 패턴은 미정.

### 스토리

플레이어가 여기저기 드나든 탓에 바이러스가 들어와 보안 앱이 감염됐다. 바이러스는 플레이어가 건드린 파일을 모두 지우려 한다. 플레이어가 싸우는 동안 폰 주인은 곡을 완성해 이번에는 직접 인스타에 올린다. 마지막에 플레이어는 바이러스 왕과 함께 쓰러진다.

### 라운드 구성

1. **1라운드 · 잡몹맵:** 일반 몹을 상대하는 전투 구간.
2. **2라운드 · 보스전 진입 과정:** 장애물, 약간의 플랫포머, 일반 적을 지나 보스전 장소로 향한다.
3. **3라운드 · 보스전:** 가만히 있는 고정형 보스와 움직이는 이동형 보스, 총 2명이 등장한다.

### 보스전의 핵심 규칙

- 이동형 보스를 먼저 2번 그로기시켜야 한다.
- 그로기 2회를 달성하기 전에는 고정형 보스에게 피해를 줄 수 없다.
- 그로기 2회를 달성하면 고정형 보스를 공격해 피해를 줄 수 있다.
- 두 보스는 각각 고유 패턴을 가진다. 구체적인 패턴 내용은 미정.

### 전투 기믹

- 원거리 상호작용 장치: 엄폐물 생성, 플랫폼 생성, 폭발물, 플랫폼 위치 변경.
- 적에게 스캔이 닿으면 약점 부위가 생기고, 약점을 맞히면 치명상을 입힌다.
- 차지샷은 우클릭 유지로 반복 발사하지만 일반 사격보다 빠르게 과열된다.

### 클리어 뒤

- 보스와 함께 쓰러지며 플레이어 사망.
- 마지막 로비에서 라이브 앱에 불이 들어오고, 라이브 씬으로 들어가는 컷신이 재생된다.

### 미정

- 1·2라운드 적 구성, 장애물·플랫포머 배치, 라운드별 종료 조건.
- 각 보스의 구체적 패턴, 이동형 보스의 그로기 발생 조건.
- 고정형 보스의 공격 가능 시간, 그로기 횟수 초기화·반복 여부.
- 두 보스의 처치 조건과 전투 종료 판정, 실제 등장 위치.
- 기존 스토리의 바이러스 왕이 두 보스 중 어느 보스인지.

## 11. 라이브 (엔딩)

조작 없음 / 마무리 씬

### 라이브 화면 구성

스마트폰 모양의 화면 안에 LIVE 표시와 노래하는 폰 주인의 영상이 나온다.

원본 도식 설명: 폰 밖에서 노래하는 주인의 영상이 라이브 방송으로 재생되는 화면.

### 스토리

좋은 반응이 이어지고 공연 제안이 들어온다. 실패가 두려워 망설이던 폰 주인은 결국 무대에 선다. 플레이어는 그 공연을 지켜보지 못하고 쓰러졌고, 화면에는 노래하는 폰 주인의 라이브 영상만 남는다. 무대에 서기로 한 것은 폰 주인 자신의 선택이었다.

### 맵 구성

- 내부 맵 없이, 라이브 영상이 재생되는 씬 하나로 끝낸다.
- 기획서의 “입장 직전에 소멸”은 “보스와 함께 쓰러진 뒤 로비 컷신”으로 바뀌었다.

## 12. 스토리

메인 스토리 1

### 전체 흐름

| 구간 | 일어나는 일 |

| 튜토리얼 | 폰 주인이 폰을 떨어뜨리고, 오류 데이터인 플레이어가 생긴다. 공개하지 않은 미완성 데모곡을 발견하고, 노래가 좋다고 느껴 폰 주인을 돕기로 한다. |
| 피드 | 플레이어가 데모곡을 몰래 인스타에 올리고 피드를 조정해 노래를 알린다. 반응이 좋자 폰 주인이 게시물을 남겨 두고 다시 작업을 시작한다. |
| 파일 | 곡을 완성하는 데 필요한 자료를 플레이어가 미로에서 모은다. 예전 가사 메모, 멜로디 녹음, 코드 진행, 데모 파일. |
| 보안 | 폰 주인이 회수한 자료로 곡을 완성하고 이번에는 직접 인스타에 올린다. 그동안 플레이어는 보안 앱에서 바이러스와 싸우고, 바이러스 왕과 함께 쓰러진다. |
| 로비 (마지막) | 좋은 반응과 공연 제안이 이어진다. 폰 주인은 고민 끝에 공연에 서기로 한다. 라이브 앱에 불이 들어온다. |
| 라이브 | 폰 주인이 공연하는 모습으로 끝난다. |

기획서에 있던 “로비에서 댓글, DM, 응원 메시지를 폰 주인에게 전달하는 장면”은 뺐다.

### 플레이어가 폰 주인을 돕는 이유

1. 스마트폰 안의 데이터는 원래 감정이 없다.
2. 플레이어는 시스템 오류로 생긴 존재라서 감정을 갖게 됐다.
3. 잠긴 노래 파일의 이름은 “이번에도 떨어지면 이제 그만해야겠다”였다. 인간의 감정이 데이터로 남을 수 있다는 것을 알게 된다.
4. 노래를 들으며 처음으로 “좋다”는 감정을 느낀다.
5. 이런 노래를 더 들을 수 없게 되는 것이 싫다. 폰 주인이 음악을 포기하려는 모습도 보게 된다.
6. 이 사람이 다시 노래를 만들었으면 좋겠다고 생각한다.

표현할 수 있을지는 미정: 플레이어는 있어서는 안 되는 오류이고, 폰 주인은 인정받지 못한 음악가라서 서로 닮았다고 느낀다.

### 지키려는 느낌

- 플레이어는 “내가 이 곡을 만든 건 아니지만 내가 도왔다”고 느끼게 한다.
- 폰 주인은 노래 자체가 좋아서 성공한다. 플레이어는 돕는 쪽이고, 스스로 성공할 재능이 원래 있었다.
- 마지막 공연에 설지 말지는 플레이어가 도왔더라도 결국 폰 주인의 선택이었음을 보여 준다.

### 미정 · 메인 스토리 2

- 주인공이 자신이 왜 태어났는지 모른 채 스마트폰 속을 돌아다니며 탄생의 단서를 찾는 이야기. 메인 스토리 1과 함께 넣을 수 있을지 정해지지 않았다.

## 13. 확인 필요

아직 정하지 않은 것

- **블루투스 세부 동작**: 탈것 형태와 이동 권한, 이동·점프속도 증가량, 방향 전환·감속, 마지막 요시점프의 입력·발동 조건·탑승 해제 여부.
- **차지샷 세부 규칙**: 충전 기준값·충전 시간·반복 간격·피해량·과열 증가량, 미달 시 일반 총알의 발사 판정 시점과 버튼 해제 처리. 우클릭 조준 병행 여부와 좌우 클릭 동시 입력.
- **스캔 수치**: 스캔 범위와 표시 지속시간. 대상별 접촉 효과는 시스템 절에 정리.
- **미로에서 죽었을 때**: 기획서는 라운드마다 다시 시작, 맵 답변은 스테이지 처음부터. 이 보드는 스테이지 처음부터로 적었다.
- **추락 피해량과 회복 아이템**: 추락 때 깎이는 체력, 스테이지 안 회복 아이템을 실제로 둘지.
- **로비 앱 잠금**: 순서가 안 된 앱 입구를 막는 방법과 표시.
- **미끼 피드 제거 4 · 5번**: 그리고 제거 뒤 날아오는 악성 데이터 조각의 추가 시점.
- **보안 3라운드 · 보스 2명**: 라운드별 적·장애물·종료 조건, 두 보스의 개별 패턴·위치·처치 조건. 이동형 그로기 발생 조건, 고정형 공격 가능 시간과 그로기 횟수 초기화·반복 여부. 바이러스 왕의 역할.
- **수치**: 플레이어의 MoveSpeed, JumpPower, BulletRange, InteractionRange. 적 수치 전부.
- **적 드랍 보상**: 배터리 충전, 체력 회복을 떨어뜨릴지.
- **UI**: UI 위치, 스킬 사용 가능 표시, 다음 스테이지 안내 여부.
- **메인 스토리 2**: 주인공의 정체 찾기를 함께 풀지.
