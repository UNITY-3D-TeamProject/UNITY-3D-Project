## 문제 (Problem)
현재 보스 체력바는 `거대 보스`와 `필드 보스`라는 글자만으로 구분되어 보스의 정체를 바로 알아보기 어렵다.

## 기대 결과 (Proposed outcome)
- 보스 A와 B의 얼굴을 정면에서 찍은 초상화를 각 체력바 옆에 표시한다.
- 보스 A의 명칭은 전투 초반부터 `최종보스`, B는 `필드보스`로 표시한다.
- 기존 체력 표시와 활성 보스의 위아래 자리 전환은 유지한다.

## 영향 범위 (Affected users and systems)
- 보안 맵 보스전 플레이어.
- `Canvas_InGame`의 `BossHealth` UI 및 보스 초상화 에셋.

## 제약 (Constraints)
- 게임플레이, 보스 단계, 데미지 로직은 변경하지 않는다.
- 다른 사용자의 기존 작업 파일 변경은 보존한다.

## 열린 질문 (Open questions)
- 없음. 보스 A의 표시 시점은 사용자가 전투 초반부터라고 확정했다.

## 해결 기록 (Resolution)
- 최종 결정: 보스 프리팹의 정면을 렌더링한 정적 초상화 2개를 `Canvas_InGame/BossHealth` 각 체력바의 왼쪽에 배치했다. A는 큰 모델의 가슴 문양이 아닌 상단의 붉은 가로 눈을 중심으로 촬영했다. A는 전투 시작부터 `최종보스`, B는 `필드보스`로 표기한다. 기존 체력과 자리 전환 로직은 유지했다.
- 검증: Unity 프리팹 미리보기 렌더에서 초상화·문구·체력바 배치를 확인했다. `git diff --check` 통과.
