## 문제 (Problem)
- 왼쪽 위 `Canvas_InGame/Active Mission` 패널의 제목 줄(`N라운드`) 앞에도 본문과 같은 동그라미가 붙어 있어 제목과 본문이 구분되지 않는다.
- 파일 앱 2라운드(숫자 퍼즐) 본문 `목표 12 · 숫자 3 5 _ · 연산 + _`가 한 줄에 몰려 패널 폭을 거의 다 채운다.
- 파일 앱 3라운드 본문 `남은 도둑 17명 · 남은 시간 45초`가 패널 폭을 넘쳐 두 줄로 꺾이고 `45초`가 패널 밖으로 잘린다.

## 기대 결과 (Proposed outcome)
- 모든 앱·라운드에서 제목 줄 앞 동그라미를 없앤다. 본문 줄 동그라미는 그대로 둔다.
- 숫자 퍼즐은 3줄로 보여 준다.
  - 2번째 줄: `목표 : 12`
  - 3번째 줄: `숫자 : 3 5 _  연산자 : + _` (앞에 동그라미 있음)
- 패널은 3줄이 들어가는 크기로 키우고, 모든 문구가 같은 패널 크기를 쓴다. 2줄짜리 문구는 줄 높이와 글자를 키워 같은 크기를 채운다.
- 도둑 잡기 남은 시간은 화면 위 가운데에 새 패널을 만들어 `남은 시간 45초`로 보여 준다. 왼쪽 위 본문은 `남은 도둑 17명`만 남긴다.
  - 새 패널은 도둑 잡기 라운드 진행 중에만 보이고, 다 잡으면 숨긴다.

## 영향 범위 (Affected users and systems)
- 누가 사용하는가: 피드·파일·보안 앱을 플레이하는 사람
- 어떤 시스템/모듈이 건드려지는가: UI `InfoPanelView`·`InfoPanelPresenter`, 새 `RoundTimerView`, `Canvas_InGame` 프리팹(`Active Mission`, 새 `Round Timer`)

## 제약 (Constraints)
- 지켜야 할 정책:
  - Core/Stage(`FileApp`·`ThiefChaseRound` 등)는 수정하지 않는다. 패널은 지금 공개된 값만 읽는다.
  - 맵 씬은 수정하지 않는다.
- 쓰지 말아야 할 것:
  - 줄 수에 따른 새 레이아웃 시스템. 기존 VerticalLayoutGroup 줄에 높이·글자 크기만 바꾼다.

## 열린 질문 (Open questions)
- 없음. 2026-10-26 사용자 결정:
  - 2줄 문구는 3줄 패널과 같은 크기, 글자를 키워 채운다.
  - 3번째 줄 앞에도 동그라미를 붙인다.
  - 남은 시간은 위 가운데 별도 패널로 뺀다.

## 진행 기록
- 2026-10-26: 구현 완료.
  - `InfoPanelView`: 셋째 줄(`_extraText`)과 `SetTexts(title, body, extra)`를 추가했다. 셋째 줄이 없으면 줄 높이 56.5·글자 32로 키워 세 줄(높이 121)과 같은 크기를 채운다.
  - `InfoPanelPresenter`: 숫자 퍼즐을 `목표 : N` / `숫자 : …  연산자 : …` 세 줄로 바꿨다. 도둑 잡기 본문은 `남은 도둑 N명`만 남기고, 남은 시간은 새 `RoundTimerView`(위 가운데 `Round Timer`)에 보여 준다.
  - `Canvas_InGame`: `Active Mission` 폭 350→400, 제목 줄 동그라미(`Icon`) 끄기, 제목 글자 왼쪽 10, 각 줄 글자 세로 늘리기, `Mission Example (2)` 추가, `Round Timer` 추가(기본 꺼짐).
  - 확인: 컴파일 에러 0. `Map_3_File` Play에서 StageManager 라운드 번호를 바꿔 2라운드 세 줄(`목표 : 47`), 3라운드 `남은 도둑 1명` + 타이머 `남은 시간 180초`, 1라운드로 돌아가면 타이머가 숨는 것을 확인했다. 나머지 문구는 View에 직접 넣어 화면을 확인했다.
- 2026-10-26: 빈 칸 `_ _ _`가 `___`처럼 붙어 보이던 문제를 고쳤다. 칸 사이를 두 칸(`HELD_SEPARATOR`)으로, 숫자·연산자 묶음 사이를 네 칸으로 띄웠다. `Map_3_File` Play에서 빈 칸과 일부 채운 칸(`3  5  _` / `+  _`) 모두 떨어져 보이는 것을 확인했다.
- 2026-10-26: 사용자 요청으로 피드·보안 진행 문구도 세 줄로 나눴다.
  - 피드 1라운드 `피드 재료 모으기` / `3/5`, 2라운드 `피드 분류` / `3/8`
  - 보안 1·2라운드 `구역 2/4`·`발판 3/5` / `남은 적 5명`
  - 클리어 문구와 보스 라운드는 두 줄 그대로다.
  - 확인: `Map_2_Feed` 1라운드, `Map_4_Security` 1·2·3라운드를 Play에서 실제 값으로 확인했다(보안은 라운드 번호를 리플렉션으로 바꿈). 피드 2라운드는 View에 직접 넣어 확인했다.
- 2026-10-26: 사용자 요청으로 제목(`N라운드`)을 가운데 정렬했다. 프리팹 제목 글자를 `Center`로 바꾸고 왼쪽 여백을 0으로 했다. `Map_4_Security` Play에서 세 줄·두 줄 모두 확인했다.
- 2026-10-26: 사용자 요청으로 타이머 문구를 `남은시간 : 165초` 형식으로 바꿨다(프리팹 기본 글자도 같게). `Map_3_File` Play 전체 화면에서 확인했다.
- 남은 일: 직접 플레이로 확인.
