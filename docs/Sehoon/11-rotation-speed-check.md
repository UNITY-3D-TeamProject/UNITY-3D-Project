# 11. 플레이어 회전 속도 체크

- **우선순위**: 중간
- **상태**: 대기

## 목표
플레이어 몸통 회전 속도가 조작감에 맞는지 점검하고, 필요하면 조정한다.

## 현재 상황
- `CharacterRotator._rotateSpeed = 720`(도/초), `Mathf.MoveTowardsAngle` 로 yaw 를 회전한다 (`Assets/_Project/Scripts/Rotation/CharacterRotator.cs:20`, `:76`).
- 고정 각속도라서 180도 회전에 약 0.25초가 걸린다 (계산값, 실측 아님). 인스펙터/프리팹에서 값이 덮어써졌는지는 아직 확인하지 않았다.

## 확정 사항
- 문제: **급격하게 방향을 틀 때 몸이 느리게 따라온다.** 원인 확인 후 수정이 필요하다.

## 작업 순서
1. 원인 확인: 프리팹의 실제 `_rotateSpeed` 값, 목표 방향 계산 지연(입력/카메라 기준), 애니메이션 루트 회전 간섭 여부를 확인한다.
2. 확인 결과와 수정안을 보고하고 승인 후 수정한다.

## 열린 질문
- [ ] **(작업 전 확인)** 문제가 나는 상황: 이동 방향을 틀 때인가, 카메라(조준)를 돌릴 때인가, 둘 다인가? → 작업 시작 시 플레이 모드에서 직접 재현해 확인한다.
- [ ] 원하는 느낌: 즉시 회전(스냅)인가, 빠르지만 부드러운 회전인가?
- [ ] 수정 방식은 원인 확인 후 선택지로 제시한다. (각도 차이가 클수록 빠르게 / 속도 값 상향 / 상황별 속도 분리 등)

## 완료 기준
- 확인된 문제 상황에서 회전이 의도대로 동작.
