# 12. Idle 시 특수 애니메이션

- **우선순위**: 중간
- **상태**: 완료

## 목표
일정 시간 입력이 없으면 특수 Idle 애니메이션을 재생한다.

## 작업 범위 (예상)
- 대기 시간 측정 → Animator 트리거, 입력·이동 시 즉시 해제 (`player-animation` 스킬 절차를 따른다).

## 열린 질문
- [x] 발동까지 대기 시간(초)은?
  - 10초 (사용자 선택).
- [x] 특수 애니메이션 개수: 1개 고정인가, 여러 개 중 랜덤인가?
  - 2개 중 랜덤 1개 (사용자 지정).
- [x] 사용할 애니메이션 클립은?
  - 32번 `Anim_ZMIKE_IdleBreaker.fbx : Idle_Breaker` (5.97초), 51번 `Anim_ZMIKE_WaveLoop.fbx : Wave_Loop` (1.63초). 둘 다 제자리 클립이고 임포트 설정은 루프다 (사용자 지정, 클립 정보는 MCP 로 확인).
- [x] 1회 재생 후 일반 Idle 로 돌아가 다시 대기 시간을 세는가? 반복 주기는?
  - 32번은 1회, 51번은 2회(약 3.3초) 재생 후 일반 Idle 로 돌아가 대기 시간을 처음부터 다시 센다. 입력이 없으면 10초마다 다시 랜덤 재생 (사용자 선택).
- [x] 해제 조건: 이동만인가? 카메라(마우스) 회전, 사격 입력도 포함하는가?
  - 이동, 점프, 구르기, 사격(차지 포함), 카메라 회전 모두 대기 시간을 초기화하고 재생 중인 특수 모션을 끊는다 (사용자 선택).
- [x] (추가) 대기 시간을 세는 상태는?
  - 바닥 Idle 상태이고 사격 상체가 꺼진 뒤(마지막 사격 후 3초 유지가 끝난 뒤)부터 센다 (사용자 선택).
- [x] (추가) 같은 모션이 연속으로 나와도 되는가?
  - 완전 랜덤(50:50), 연속 허용 (사용자 선택).

## 완료 기준
- 무입력 대기 후 특수 모션 재생, 입력 시 자연스럽게 복귀.

## 구현 결과
- `CharacterAnimator` 가 Base Layer Idle + 사격 상체 꺼짐 상태에서 무입력 시간을 세고, 10초가 되면 `SpecialIdleIndex`(랜덤) · `IsSpecialIdle` · `SpecialIdle`(Trigger)을 설정한다. 이동·점프·구르기·사격·차지·카메라 회전 호출 시 시간을 초기화하고 `IsSpecialIdle` 을 끈다. 새 이벤트·공개 시그니처·프리팹 변경 없음.
- `PlayerAnimator.controller` Base Layer 에 `SpecialIdleBreaker`(32), `SpecialWave`(51) 상태와 전환을 추가했다. 진입 0.25초, Idle 복귀 0.2초, Locomotion 0.1초, 자연 종료 Exit Time 1.0 / 2.0.
- 상세 구성은 `.claude/skills/player-animation/player-animation-reference.md` 5장.
- 검증: Play 모드에서 자동 발동·자연 종료·재발동, 이동·카메라 해제(입력 경로 메서드 직접 호출) 확인. 실제 키·마우스 입력 해제와 점프·구르기·사격 해제는 Play 로 확인하지 못했다. 사용자 확인 완료.
