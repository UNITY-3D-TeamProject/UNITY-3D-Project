# 14. 사격·조준 중 이동 속도 감소

- **우선순위**: 낮음
- **상태**: 완료
- **관련 작업**: [04. Fire 차지샷](04-fire-charge-shot.md), [05. 대쉬 중 사격·Aim 규칙](05-dash-fire-aim-rules.md)

## 목표
사격하거나 조준하는 동안 이동 속도를 줄인다.

## 확정 사항
- 사격 시: 이동 속도 **50 감소**
- 조준 시: 이동 속도 **150 감소**
- 조준 + 사격 시: **150 감소** (합산하지 않는다)
- "사격 시"는 **차지 중**(Fire 홀드, 차지 시작 ~ 발사·취소)으로 본다.
- 감소량은 `MoveSpeed` 절댓값 차감이며, 50 / 150 대신 **1.5 / 3** 을 쓴다. 두 값은 이동속도 결정 컴포넌트에서 인스펙터로 노출한다.
- 감소는 상태가 바뀌는 즉시 적용·해제한다.
- "조준 중"은 실제 조준 카메라 상태로 판정한다 (구르기로 조준이 잠기면 감속도 해제).
- 감속은 어트리뷰트 `MoveSpeed` 를 직접 변경해 반영한다.
- 흐름: 각 컴포넌트 → 각 중재자 → `CharacterMediator` → `CombatMediator` → 이동속도 결정 컴포넌트. 결정 컴포넌트가 감속량을 정하고 이동속도를 제어한다.

## 현재 상황
- 플레이어 이동 속도는 어트리뷰트 `MoveSpeed` 다 (`Assets/_Project/ScriptableObjects/SOAttributeData_Player.asset`, 현재 값 5).
- 04 에서 차지 중 이동 감속은 범위에서 제외했다.
- Aim 입력 눌림 상태는 `CameraMediator` 가 보관한다(`_isAimInputHeld`). 구르기 중에는 조준 카메라를 잠그고, 종료 시 눌림 상태대로 복구한다 ([05](05-dash-fire-aim-rules.md)).

## 열린 질문
- [x] "50 / 150 감소" 의 단위: `MoveSpeed` 절댓값 차감. 값은 1.5 / 3 으로 쓴다.
- [x] "사격 시" 의 범위: 차지 중(Fire 홀드)으로 본다.
- [x] 감소 적용·해제 시 즉시 바뀐다.

## 완료 기준
- 플레이 모드 확인: 사격 중 / 조준 중 / 조준 + 사격 중 각각의 이동 속도가 확정 값대로 줄어든다.
- 컴파일 에러 없음.
