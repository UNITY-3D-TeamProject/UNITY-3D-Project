# 08. 블루투스 모션 추가

- **우선순위**: 높음
- **상태**: 대기
- **선행 작업**: [07. 스킬 구현](07-skill-implementation.md) (블루투스 스킬)

## 목표
블루투스 스킬(탈것 소환·탑승)을 쓸 때 재생할 플레이어 애니메이션을 추가한다.

## 작업 범위 (예상)
- Animator 파라미터·스테이트 추가, `CharacterAnimator` 에 트리거 연결 (`player-animation` 스킬 절차를 따른다).

## 열린 질문
- [ ] 필요한 모션 구성: 탑승(시작) / 탑승 중(루프) / 하차 중 어떤 것이 필요한가?
- [ ] 사용할 애니메이션 클립(파일명/경로)은?
- [ ] 탑승 중에는 기존 이동 블렌드(Idle/Run/점프)를 대체하는가, 하체만 탑승 자세로 고정하는가?
- [ ] 탑승 중 상체 레이어(사격)는 그대로 쓰는가?

## 완료 기준
- 플레이 모드에서 블루투스 스킬 발동 시 모션 재생 확인.
