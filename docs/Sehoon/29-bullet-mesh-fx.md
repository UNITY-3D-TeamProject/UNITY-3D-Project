# 29. 총알 메시 + FX

- **우선순위**: 미정
- **상태**: 대기
- **관련 작업**: [28. 총알 오브젝트 풀 연동](done/28-bullet-object-pool.md) — 풀 재사용 시 FX 초기화가 필요하다. [30. 사운드 + VFX](30-sound-vfx.md)

## 목표
총알을 임시 구체에서 실제 메시로 바꾸고, 비행·피격 FX 를 붙인다.

## 현재 상황
- `Bullet.prefab` 메시는 Unity 기본 Sphere(fileID 10207)다. `ChargedBullet.prefab` 은 Bullet 변형으로 머티리얼만 바꿨다.
- `BulletController` 는 피격 시 효과 적용 후 바로 `Destroy` 한다. 피격 FX 생성 지점이 없다.

## 작업 범위 (예상)
- 일반/차지 총알 메시·머티리얼 교체, 트레일 등 비행 FX.
- 피격(명중) FX, 수명 종료 시 처리.
