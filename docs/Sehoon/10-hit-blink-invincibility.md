# 10. 피격 시 플레이어 깜빡임 + 무적

- **우선순위**: 중간
- **상태**: 대기
- **관련 작업**: [09. Hit 방향별 모션](09-directional-hit-motion.md)

## 목표
피격 후 일정 시간 무적이 되고, 그동안 플레이어가 깜빡인다.

## 현재 상황
- 피격은 `CharacterCombat.Health` 감소로 판정된다. 데미지는 공격 측이 어트리뷰트에 직접 적용하므로, 무적 중 **데미지 자체를 어디서 막을지** 정해야 한다.

## 열린 질문
- [ ] 무적 시간(초)과 깜빡임 주기는?
- [ ] 깜빡임 방식: 렌더러 on/off? 머티리얼 색/알파 변경? (셰이더 의존 여부)
- [ ] 무적 중 막는 대상: 모든 데미지인가, 특정 효과만인가? 피격 모션(09)도 막는가?
- [ ] 차단 위치: 공격 측(`BulletController`/`MeleeHitController`)에서 판정 / 어트리뷰트 적용 단계에서 차단 / 기타?
- [ ] 구르기(Roll) 중 무적도 같은 시스템으로 처리할 계획이 있는가?
- [ ] 플레이어 전용인가, 적에게도 쓰는가?

## 완료 기준
- 플레이 모드에서 피격 후 설정 시간 동안 추가 데미지가 없고 깜빡이는지 확인.
