# 02. 멀티점프

- **우선순위**: 최우선
- **상태**: 대기
- **관련 작업**: [03. 점프 중 대쉬 1회 제약](03-air-dash-limit.md)

## 목표
`DoubleJump` 를 멀티점프로 바꿔, 정해진 횟수만큼 연속 점프할 수 있게 한다.

## 현재 상황
- `DoubleJump.cs` 는 `Debug.Log` 만 찍는 빈 껍데기다 (`Assets/_Project/Scripts/Skill/Skills/DoubleJump.cs`).
- 접지 판정: `CharacterMotor.IsGrounded` (`Assets/_Project/Scripts/Movement/CharacterMotor.cs:64`).

## 확정 사항
- `DoubleJump` 를 멀티점프로 변경하고 **클래스 이름도 바꾼다**.
- 멀티점프 점프 파워 = 기존 점프 파워의 **절반**.
- 멀티점프 가능 횟수를 값으로 가진다. 횟수는 **첫 점프를 포함**한다.

## 작업 범위 (예상)
- 클래스 이름 변경, 횟수 카운트와 착지 시 초기화, 절반 점프 파워 적용.

## 열린 질문
- [ ] 새 클래스 이름: `MultiJump` 로 하면 되는가? (이름 변경 시 `.meta` GUID 를 유지해 프리팹 참조가 끊기지 않게 한다)
- [ ] 가능 횟수 기본값은? (첫 점프 포함. 예: 2 = 지상 점프 1 + 공중 점프 1)
- [ ] 첫 점프는 지금처럼 기존 점프 처리가 맡고 멀티점프는 공중 점프만 담당하는가, 멀티점프가 첫 점프까지 통합해 관리하는가?
- [ ] 발판에서 떨어진 뒤(점프 없이 공중) 점프하면 첫 점프로 치는가, 공중 점프로 치는가?
- [ ] "기존 점프 파워"는 `JumpPower` 어트리뷰트 현재값 기준인가? (블루투스 버프로 점프 파워가 늘면 멀티점프도 같이 느는가)
- [ ] 멀티점프 전용 애니메이션이 필요한가?
- [ ] 입력 키 / 쿨타임 / 코스트 값

## 완료 기준
- 플레이 모드에서 설정 횟수만큼 점프 가능, 공중 점프는 절반 파워, 착지 후 횟수 초기화 확인. 컴파일 에러 없음.
