# 04. Fire 구조 차지샷으로 변경

- **우선순위**: 최우선
- **상태**: 대기
- **관련 작업**: [06. Heat 게이지 구조 수정](06-heat-gauge-fix.md) — 차지샷은 기존 코스트 구조로 먼저 구현하고, 06에서 코스트를 `HeatCost` 로 교체한다.

## 목표
지금의 연사 구조(누르는 동안 일정 간격 사격)를 차지샷 구조로 바꾼다.

## 현재 상황
- `Fire.cs`: 발동 시 첫 발을 쏘고, 코루틴으로 `_duration` 간격마다 재발동, `Stop()` 으로 종료한다 (`Assets/_Project/Scripts/Skill/Skills/Fire.cs`).
- 사격 1회마다 코스트를 지불한다. Heat 증가·과열 잠금은 06에서 처리한다.

## 확정 사항
- 연사를 **완전히 대체**한다. 발사는 **차지된 샷 / 차지 안 된 샷** 두 종류뿐이다.

## 작업 범위 (예상)
1. 누르는 동안 차지 시간 누적 → 떼는 순간 차지 여부에 따라 두 종류 중 하나를 발사.
2. 차지 여부를 투사체에 전달 (`BulletFactory` / `BulletController` 영향 가능).

## 열린 질문
- [ ] 차지 완료까지 걸리는 시간은?
- [ ] 차지 안 된 샷 / 차지된 샷의 차이: 데미지 / 크기 / 속도 / 관통 중 무엇인가?
- [ ] 차지 안 된 샷을 연타할 때 최소 발사 간격이 있는가?
- [ ] 샷 종류별 Heat 증가량은? 차지 중에도 Heat 가 오르는가?
- [ ] 차지 중 과열 잠금에 걸리면(차지 중 Heat 증가 시) 차지가 취소되는가?
- [ ] 차지 중 이동 속도 감소나 이동 제한이 있는가?
- [ ] 차지 중 애니메이션/이펙트도 이번 범위에 포함하는가?
- [ ] 적(`EnemyRangedAttack`)에는 영향 없이 플레이어만 바꾸는 것이 맞는가?

## 완료 기준
- 누름/뗌 입력으로 두 종류 샷 발사 확인. 기존 총구·투사체 방향 조정 동작 유지.
