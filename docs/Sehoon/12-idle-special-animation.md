# 12. Idle 시 특수 애니메이션

- **우선순위**: 중간
- **상태**: 대기

## 목표
일정 시간 입력이 없으면 특수 Idle 애니메이션을 재생한다.

## 작업 범위 (예상)
- 대기 시간 측정 → Animator 트리거, 입력·이동 시 즉시 해제 (`player-animation` 스킬 절차를 따른다).

## 열린 질문
- [ ] 발동까지 대기 시간(초)은?
- [ ] 특수 애니메이션 개수: 1개 고정인가, 여러 개 중 랜덤인가?
- [ ] 사용할 애니메이션 클립은?
- [ ] 1회 재생 후 일반 Idle 로 돌아가 다시 대기 시간을 세는가? 반복 주기는?
- [ ] 해제 조건: 이동만인가? 카메라(마우스) 회전, 사격 입력도 포함하는가?

## 완료 기준
- 무입력 대기 후 특수 모션 재생, 입력 시 자연스럽게 복귀.
