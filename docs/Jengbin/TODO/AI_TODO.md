## 보스전 구조 및 HP UI 설계

### 전투 구조 — 확정

| 구간 | 작은 보스 | 큰 보스의 피해 가능 여부 |
|---|---|---|
| 전투 시작 | 첫 번째 HP 소진 목표 | 피해 불가 |
| 작은 보스 첫 HP 0 (1-1) | 제거되지 않고 그로기 | 잠시 연동 그로기, 이때만 피해 가능 |
| 그로기 종료 후 | 전투 복귀, 두 번째 HP 소진 목표 | 다시 피해 불가 |
| 작은 보스 두 번째 HP 0 | 전투에서 제거 | 이후 계속 피해 가능, 단독 페이즈 진행 |
| 큰 보스 HP 0 | 제거된 상태 | 보스전 클리어 |

- 작은 보스가 살아 있는 동안 큰 보스는 연동 그로기 중에만 피해를 받음.
- 첫 연동 그로기에서 큰 보스 HP는 최대 HP의 60% 아래로 내려가지 않음.
  - 사용자 확인: 해당 HP 하한은 이미 내부적으로 설정되어 있음. 이번 작업에서 코드 검증을 수행한 것은 아님.
- 작은 보스 제거 후에는 큰 보스가 계속 피해를 받으며 최종 처치 가능.

### HP UI 적용 방향 — 현재 게임 화면에 맞춘 목업 기준

- 기존 HUD의 청록색 네온 테두리, 각진 패널, 어두운 반투명 배경을 사용.
- 좌측 상단 목표 UI 오른쪽의 상단 중앙 영역에 큰 보스 주 체력바 배치.
- 작은 보스 보조 체력바는 주 체력바 아래에 더 작은 크기로 배치.
- 큰 보스 피해 불가 상태는 잠금 아이콘·빗금·채도를 낮춘 체력바로 구분.
- 현재 공격 가능한 대상은 노란색 계열과 상태 표시로 강조.
- 큰 보스의 초기 60% HP 하한은 체력바에 경계선으로 표시하고, 단독 페이즈에서는 제거.
- 연동 그로기에는 큰 보스 잠금 표시를 해제하고 공격 기회를 강조.
- 작은 보스 첫 HP 0에는 빈 체력바와 그로기 표시를 유지해 최종 처치와 구분.
- 작은 보스 복귀 시 회복된 HP를 표시하고, 최종 제거 시 보조 체력바를 숨김.
- 큰 보스 체력바는 단독 페이즈에도 같은 위치에서 유지.
- 실제 UI의 패널 높이·간격·발광 강도는 전투 시야와 가독성을 보며 조정. 목업의 `BOSS A/B`는 임시 이름임.

### 남은 결정 및 검증

- 작은 보스 첫 그로기 종료 후 회복할 HP 양과 복귀 시점.
- 잡몹 힛모션 길이와 경직 종료 후 재경직 방지 시간.
- 연사를 지속해도 잡몹이 무한 경직에 묶이지 않고 공격을 시작·완료할 수 있는지 확인.
- 큰 보스의 피해 가능 구간, 초기 60% HP 하한, 작은 보스 제거 후 단독 페이즈가 UI 표시와 일치하는지 확인.
