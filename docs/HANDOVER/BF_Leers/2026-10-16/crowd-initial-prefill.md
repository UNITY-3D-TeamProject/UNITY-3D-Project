# 열린 군중 레인 시작 시 미리 깔기

- 작업자: BF_Leers
- 날짜: 2026-10-16
- 관련 intent: [intent-017](../../../intent/intent-017-lobby-crowd.md)

## 1. 작업 요약 및 방법
Play 직후 군중이 아예 없다가 하나씩 나타나는 느낌이 어색해서, 열린 레인은 씬 시작 시 일부를 미리 깔도록 바꿨다.

- `CrowdLane`: `_initialFillRatio`(0~1, 기본 0.3)를 추가했다. 열린 레인의 `Start()` 가 `FillInitialMembers()` 를 호출해 `_spawnCount × 비율`(반올림)개를 0번 스플라인 위에 균등한 칸으로 나눠 놓고, 칸 안에서 위치를 흔든다. 흔들림은 `(칸 - _minSpacing) / 2` 로 제한해 이웃 간격이 `_minSpacing` 아래로 내려가지 않는다. 기존 `SpawnMember(distance)` 를 재사용한다.
- `CrowdController.SetLane`: `FindNextFork(0)` 뒤에, 현재 진행 거리보다 앞에 있는 갈림길을 건너뛰는 루프를 추가했다. 레인 중간에 놓인 개체가 이미 지난 갈림길을 "도달"로 판정해 갈래 시작점으로 되돌아가는 것을 막는다.
- 나머지 개체는 기존처럼 시작점에서 랜덤 간격으로 차례대로 나온다.

## 2. 결정 사항
- 기본 비율 30% (사용자 결정). 보행자·차량 모든 열린 레인에 같은 기본값을 쓴다. 끄려면 레인에서 0.
- 균등 칸 + 무작위 흔들림 (사용자 결정). 닫힌 레인은 기존대로 전체에 깐다.
- 미리 깔기는 0번 스플라인만 대상이다. 갈래 스플라인은 지금처럼 갈림길을 지나며 채워진다.
- 씬은 수정하지 않았다. 기존 레인에는 새 필드가 저장돼 있지 않아 기본값 0.3 이 적용된다.

## 3. 현재 상태 및 이슈
- 컴파일 에러 0 (`recompile` 완료, 콘솔 에러 0).
- **Play 검증은 하지 않았다.** 레인별 미리 깔린 개수, 갈림길 앞뒤 개체의 역주행 여부, 시작 직후 육안 확인이 남았다.
- 비율이 높거나 레인이 짧으면 시작점 근처 개체 때문에 첫 스폰이 잠깐 늦을 수 있다 (기존 `IsSpawnPointClear` 가 처리).
