# 보스 육안 확인 정리

- 날짜: 2026-10-21
- 실행자: Claude 직접(문서 정리만, 코드 변경 없음)

## 1. 작업 요약 및 방법
- 사용자가 보스 A·B·아레나·실제 맵(`Map_4_Security`) 육안 확인 항목을 모두 확인했다고 알려 와, 육안 확인만 남아 있던 intent 를 resolved 로 바꾸고 `docs/intent/clear/` 로 옮겼다.
  - intent-044(B 첫 도약), 047(A 예고 중앙 채움), 048(A4 그랩 재설계), 049(B 예고 색), 050(B 착지 칸 예약), 054(칸 솟아오르기).
  - intent-057(B 돌진 구멍)은 파일이 이미 `clear/` 에 resolved 로 있었는데 `INTENT_POINTER.md` 에 열린 상태로 남아 있어 해결됨 목록으로 옮겼다. intent-050 은 포인터에 항목이 없어 해결됨에 새로 넣었다.
- 임시값은 모두 그대로 유지(칸 솟아오르기 4 m·0.35초·넘침 2, B 예고 파랑 등).

## 2. 결정 사항
- 육안 확인만으로 닫을 수 없는 intent 는 열어 둔다.
  - intent-045(B 스킬 애니메이션): Charge 종료 신호, BT Combo 가지 편집 담당이 미정.
  - intent-046(5×5 아레나): 패턴 일반화 임시 결정, A5 9칸 난이도, 손 배정 확인이 미정.
  - intent-053(Map_4 보스 칸): 16 m 빈 구간·낙사 구역은 해결로 표시. `BossArena._circlePrefab`/`_linePrefab` 연결 여부, `SafeSignals` 예고 중 처리가 미정.

## 3. 현재 상태 및 이슈
- **`Map_4_Security` 의 `BossArena._circlePrefab`·`_linePrefab` 이 아직 비어 있다**(씬 YAML 읽기로 확인, `{fileID: 0}`). 이 맵에서는 `ShowCircle` 을 쓰는 어깨포 예고 원과 `ShowLine` 을 쓰는 A4 그랩 직선 예고가 보이지 않는다. B 도약·돌진은 B 전용 예고 프리팹이라 영향 없음. 연결 여부는 사용자 결정 필요(intent-053).
- 남은 육안 확인: 잡몹-3(공격 중 피격), 잡몹-2(연사 힛모션).
- 게이트 루프 미실행, 커밋 전.

## 4. 다음 할 일 (Next Steps)

- 잡몹-3·잡몹-2 육안 확인.
