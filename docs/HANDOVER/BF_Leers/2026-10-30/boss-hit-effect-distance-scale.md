# 보스-31 — 보스 피격 이펙트 거리 비례 확대

## 작업 요약 및 방법
- 단독 패턴 때 멀리서 보스 피격 이펙트가 안 보이던 문제. 표현 방식은 사용자 결정으로 "거리 비례 이펙트 확대", 범위는 보스-31 만(이펙트-2·사운드-7 제외).
- `HitEffectFeedback` 에 `_scaleStartDistance`(15m)·`_maxScaleMultiplier`(5) 추가. 카메라↔맞은 지점 거리 / 시작 거리를 1~최대 배율로 잘라 `EffectManager.Play` 의 `scaleMultiplier` 로 넘김.
- 프리팹 수정 없음. 기존 `BossA.prefab` 은 필드 초기값(코드 기본값)을 그대로 사용.

## 결정 사항
- 확대는 `EffectManager.Play` 기존 `scaleMultiplier` 를 재사용(새 구조 없음).
- 15m·5배는 초기값. 단독 패턴 실제 거리를 모르고 정한 값이다.

## 현재 상태 및 이슈
- 리컴파일 통과(에러 0). **직접 플레이·게이트 루프 미실행, 커밋 전.**
- 연사 시 이펙트가 과하게 커지거나 쌓이는지 미확인.

## 다음 할 일
- 단독 패턴 위치에서 피격이 구분되는지 플레이 확인 후 `BossA.prefab` 의 두 값 조정.
- 이펙트-2(큰 보스 피격 이펙트)·사운드-7 은 별도 진행.
