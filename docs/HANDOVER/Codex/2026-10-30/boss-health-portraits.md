# 보스 체력바 정면 초상화

## 작업 요약 및 방법
- `BossA.prefab`과 `BossB.prefab`을 정면(+Z)에서 렌더링하여 512×512 초상화 PNG를 `Assets/_Project/Art/UI/BossPortraits/`에 만들었다. A 초안은 가슴 문양을 얼굴로 오인했으나, 프리팹 전체를 네 방향에서 다시 살펴본 후 상단의 붉은 가로 눈이 보이도록 촬영 기준 높이를 21m로 올려 교체했다.
- `Canvas_InGame/BossHealth`의 각 체력바 왼쪽에 초상화를 배치하고, 이름을 이미지 바로 옆으로 옮겼다. A는 전투 시작부터 `최종보스`, B는 `필드보스`로 표시한다.
- 체력 트랙의 왼쪽만 줄여 초상화와 겹치지 않게 했다. `BossHealthView`·`BossHealthPresenter`의 로직은 변경하지 않았다.

## 결정 사항
- 실시간 RenderTexture가 아닌 프리팹에서 촬영한 정적 Sprite를 사용한다.
- 활성 보스의 위쪽·큰 바, 비활성 보스의 아래쪽·작은 바 전환은 유지한다.

## 현재 상태 및 이슈
- Unity 프리팹을 임시 렌더링해 이미지·문구·체력바 위치를 육안 확인했다. `git diff --check` 통과.
- 실제 `Map_4_Security` 플레이 중의 화면은 확인하지 않았다. 씬 파일은 수정하지 않았다.
- 작업 전부터 있던 다른 파일의 변경은 건드리지 않았다. 커밋하지 않았다.
