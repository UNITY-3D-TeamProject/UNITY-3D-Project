# ThirdParty SVN 작업 사본과 프로젝트 폴더 비교

## 작업 요약
- `C:\Unity3D_Project_Assets\ThirdParty`와 `Assets/ThirdParty`를 읽기 전용으로 비교했다.
- 공통 파일 35,593개 중 8개가 내용이 다르다. 원본에만 6개, 프로젝트에만 19개 파일이 있다.

## 방법/접근
- 상대 경로와 크기를 비교하고, 크기가 같은 공통 파일 35,587개는 전체 바이트를 비교했다.
- SVN `wc.db`의 기준 정보와 원본 작업 사본을 대조했다.

## 변경된 파일
- 이 기록과 `HANDOFF_POINTER.md`만 변경했다. 에셋은 변경하지 않았다.

## 결정 사항
- 원본 폴더를 프로젝트 폴더에 일괄 덮어쓰지 않는다. 프로젝트에서 변경된 에셋 6개와 Unity `.meta` GUID 2개를 보존해야 한다.

## 현재 상태 및 이슈
- SVN 작업 사본은 r379이며 추적 파일 35,561개에 로컬 수정/삭제가 없고, 추적되지 않은 파일 39개가 있다.
- 서버의 최신 리비전과 충돌 가능성은 확인하지 못했다. `svn` CLI가 설치되어 있지 않다.

## 다음 할 일
- SVN 원본을 갱신하려면 서버 변경 내용을 먼저 확인한다. 프로젝트와 동기화할 때는 차이 파일을 개별 검토한다.
