# 라이브 엔딩 컷씬 번호 충돌 해결

## 작업 요약 및 방법
- `develop` 병합에서 `SOCutsceneTable.asset`의 34번 등록이 파일 맵 업로드 컷씬과 라이브 엔딩 대화 컷씬에 중복됐다.
- `develop`의 파일 맵 업로드 컷씬은 34번으로 유지하고 라이브 엔딩 대화 컷씬을 35번으로 변경했다.
- `ScreenVideoZoom.cs` 기본값과 `Map_5_Live.unity`의 직렬화 값을 함께 35번으로 맞췄다.

## 결정 사항
- 34번: 파일 맵 업로드 (`SOCutscene_File_Upload`).
- 35번: 라이브 엔딩 대화 (`SOCutscene_Live_AfterShow`).

## 현재 상태 및 이슈
- 사용자 요청에 따라 플레이 검증은 진행하지 않았다.
- 병합의 다른 변경 사항은 수정하지 않았다.

## 다음 할 일
- 병합을 마무리할 때 변경된 컷씬 표·스크립트·씬을 포함한다.
