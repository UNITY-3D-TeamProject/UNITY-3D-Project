# Unity 컬링 적용 안내

## 작업 요약
- Unity 컬링 적용 방법 질문에 답하기 위해 프로젝트 설정과 Unity 공식 문서를 확인했다.

## 방법/접근
- Unity 6000.4.8f1, URP 17.4.0, Cinemachine 사용을 확인했다.
- `SampleScene`의 Main Camera에 Occlusion Culling이 켜져 있지만, 씬의 베이크 데이터 참조는 비어 있음을 확인했다.
- 절두체 컬링, 오클루전 컬링, 거리 컬링의 적용 범위를 구분했다.

## 변경된 파일
- 이 기록과 `HANDOFF_POINTER.md`만 추가했다. 게임 코드와 씬은 변경하지 않았다.

## 결정 사항
- 실제 씬의 정적 지오메트리와 성능 목표가 정해지기 전에는 컬링 설정을 임의로 변경하지 않는다.

## 현재 상태 및 이슈
- 베이크 데이터가 없어 현재 씬에서 오클루전 컬링의 실효성은 확인되지 않았다.

## 다음 할 일
- 사용자가 원하는 컬링 유형과 적용 대상 씬을 확인한 뒤, 필요하면 베이크 및 성능 검증을 진행한다.
