# 커밋 분리 및 intent 문서 위치 정리

## 작업 요약 및 방법
- 현재 작업 트리의 스크립트, Effect 에셋, 문서 변경을 확인하고 세 커밋으로 나눌 메시지를 작성했다.
- 새 intent 문서와 그 항목을 담은 목차를 `docs/HANDOVER/SungJun/intent/`에 두고, 공용 목차에 추가했던 항목은 제거했다.

## 결정 사항
- 스폰 상태 처리 스크립트, 초기화 Effect 에셋, SungJun 문서를 각각 하나의 변경 단위로 제안한다.
- 실제 Git 커밋은 생성하지 않는다.

## 현재 상태 및 이슈
- Unity 컴파일과 플레이 모드 실행은 이번 문서 정리 과정에서 검증하지 않았다.
- 개인 intent 문서는 공용 `docs/intent/INTENT_POINTER.md` 목록에 표시되지 않는다.
