# 스크립트 변경 분리 커밋

- 작업 요약 및 방법: 사용자 요청에 따라 앞서 작성한 메시지의 작업자 표기를 김성준으로 변경하고, 스크립트 4개의 변경을 목적별 3개 커밋으로 저장했다. 각 커밋 직전 스테이징 경로가 지정한 파일 목록과 일치하는지 확인했다.
- 변경된 파일 및 커밋:
  - 5be5d34: GameManager.cs와 PlayerSpawner.cs — 로비 복귀 위치별 플레이어 스폰 기반 추가.
  - 1c2aa57: StageManager.cs — 스테이지 상태 프로퍼티 및 메서드명 정리.
  - b2ca3ac: FeedApp.cs — 피드 스테이지 미션 구성 메모 추가.
- 결정 사항: feature/System-Manager 브랜치에서 커밋했다. 메시지 본문에 김성준을 표기했고 Git 사용자 설정은 변경하지 않았다. 프로젝트 설정과 문서 변경은 커밋에 포함하지 않았다.
- 현재 상태 및 이슈: git log로 메시지와 포함 파일을 확인했고, 스크립트 미커밋 변경과 스테이징 항목이 없음을 확인했다. 런타임 코드는 수정하지 않았으며 Unity 실행 검증은 하지 않았다. 씬 전환 연결 관련 주석 상태는 유지된다.
- 다음 할 일: 푸시는 요청되지 않아 실행하지 않았다. 필요 시 사용자가 푸시를 요청한다.
