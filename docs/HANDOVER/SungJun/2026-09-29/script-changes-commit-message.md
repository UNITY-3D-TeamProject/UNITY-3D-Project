# 스크립트 변경 커밋 메시지 작성

- 작업 요약 및 방법: CLAUDE.md, 커밋 컨벤션과 응답 지침을 읽고 git diff로 변경된 스크립트 4개를 확인하여 커밋 메시지를 작성했다.
- 변경된 파일: 런타임 코드는 수정하지 않았다. 이 기록과 HANDOFF_POINTER.md만 갱신했다. 실제 커밋은 실행하지 않았다.
- 결정 사항: 메시지는 feat 태그와 작업자 SungJun을 사용하고, 로비 스폰 위치 선택 기반, 스폰 검증, 씬 로드 이벤트, 스테이지 상태 정리 및 FeedApp 주석 추가만 포함한다. 프로젝트 설정과 문서 변경은 메시지 대상에서 제외한다.
- 현재 상태 및 이슈: SpawnStage 설정과 씬 전환 직전 이벤트 연결, 로드 후 TakeCurrentStage 호출은 주석 상태이므로 로비 복귀 전체 흐름이 완성됐다고 기록하지 않는다. Unity 실행 검증은 하지 않았다.
- 다음 할 일: 사용자가 스크립트 변경을 커밋할 때 작성한 메시지를 활용한다.

## 커밋 메시지 분리

- 사용자의 후속 요청에 따라 변경 목적별로 메시지를 3개로 나눴다.
- GameManager.cs와 PlayerSpawner.cs는 복귀 스테이지 정보와 로비 스폰 위치 선택이 연결되므로 하나의 feat 커밋으로 묶는다.
- StageManager.cs는 상태 프로퍼티와 메서드명 정리를 refactor 커밋으로 분리한다.
- FeedApp.cs는 미션 구성 주석만 추가되어 chore 커밋으로 분리한다.
- 실제 스테이징이나 커밋은 실행하지 않았다.
