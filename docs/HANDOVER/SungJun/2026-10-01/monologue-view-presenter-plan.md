# 독백 View/Presenter 최소 구현 계획

## 작업 요약
- 비어 있는 독백 View와 Presenter를 어떤 순서와 책임으로 구현할지 검토했다.

## 방법/접근
- 현재 UI 스크립트, 프로젝트 내 텍스트 컴포넌트 사용 여부, Unity 패키지 구성을 확인했다.

## 변경된 파일
- 이 작업 기록과 `HANDOFF_POINTER.md`만 변경했다. Unity 코드는 수정하지 않았다.

## 결정 사항
- 확정된 구현 결정은 없다. View에는 패널 Root와 텍스트 참조 및 표시·숨김을, Presenter에는 문구 전달과 표시 시간 관리를 두는 최소 구성을 제안한다.
- 첫 구현에서는 새 요청이 오면 이전 독백을 교체하고 표시 시간을 다시 시작하는 단순 동작을 제안한다.

## 현재 상태 및 이슈
- `MonologueView`와 `MonologuePresenter`는 빈 클래스다. 프로젝트 내부에 독백 패널 프리팹도 없다.
- 프로젝트 스크립트에서 TMP나 `UnityEngine.UI.Text` 사용 예시는 확인되지 않았다.
- 표시 시간, 일시정지 중 동작, 중복 요청 정책은 아직 확정되지 않았다.

## 다음 할 일
- 텍스트 UI와 자동 숨김 여부를 확정하고 View, Presenter, Canvas 패널을 연결한다.
