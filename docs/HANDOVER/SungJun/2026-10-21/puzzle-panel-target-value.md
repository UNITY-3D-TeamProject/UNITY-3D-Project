# 2라운드 정보 패널에 목표값 다시 표시

## 작업 요약 및 방법
- 사용자 요청: 2라운드(숫자 퍼즐) 때 왼쪽 정보 패널(`Canvas_InGame/Active Mission`)에 목표 숫자가 안 보인다.
- 이전 작업(미로 패널 정리)에서 "목표값은 맵의 퍼즐 패널에 보인다"는 이유로 패널 본문에서 목표값을 뺐던 것을 다시 넣었다.
- `InfoPanelPresenter.BuildPuzzleText` 맨 앞에 `NumberPuzzleRound.TargetValue`를 붙였다.
  - 표시 예: `목표 12 · 숫자 3 5 _ · 연산 + _`
  - 리셋(리셋 장치·사망) 때 목표값이 바뀌면 `ResetPuzzle`이 `OnProgressChanged`를 부르므로 패널도 같이 갱신된다.

## 결정 사항
- 목표값은 맵 퍼즐 패널과 왼쪽 정보 패널 양쪽에 모두 보인다.
- 정답을 맞춘 뒤에는 기존처럼 `정답! 문이 열렸습니다`만 보인다.

## 현재 상태 및 이슈
- Unity 리컴파일 통과(에러 0).
- Play 미확인: 한 줄이 길어져 패널 글자 칸을 넘치는지 육안으로 확인하지 않았다.
- 커밋 안 함.

## 다음 할 일 (Next Steps)
- Play에서 2라운드 진입 후 패널 글자가 잘리지 않는지 확인, 잘리면 줄바꿈이나 글자 칸 크기 조정.
