# develop 병합 충돌 해결

## 작업 요약 및 방법
- 진행 중인 `develop` → `feature/ui-feed-round-progress` 병합의 유일한 충돌 파일 `docs/intent/INTENT_POINTER.md`를 해결했다.
- 현재 브랜치의 파일 앱 2개·피드 앱 1개 항목과 develop의 보스 아레나 2개 항목을 모두 유지하고 충돌 마커만 제거했다.
- 이미 자동 병합되어 스테이징된 파일은 그대로 보존했다.

## 결정 사항
- 기존 intent 문서의 번호와 상태는 변경하지 않는다. 같은 번호라도 슬러그가 다르므로 각 링크를 유지한다.

## 검증 및 현재 상태
- 충돌 블록 1개의 마커 3개만 제거했으며, 양쪽 추가 항목 5개의 링크가 존재함을 확인했다.
- 이번 수동 수정은 문서에 한정된다. Unity 실행 및 기능 테스트는 수행하지 않았다.

## 다음 할 일
