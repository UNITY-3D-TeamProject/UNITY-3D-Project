# 스캔 상호작용 HUD 제안

## 작업 요약 및 방법
- 현재 스캔 구조(`ScanTarget`, `MarkerReaction`)와 프로젝트 콘셉트(스마트폰 내부 세계의 3D 플랫포머·TPS)를 확인했다.
- 다른 게임의 스캔 화면을 참고하고, 원거리 위치 표식과 근거리 상호작용 안내를 구분한 예시 이미지를 생성했다.

## 변경된 파일
- 이 인수인계 기록 외 게임 코드와 에셋 변경 없음.

## 결정 사항
- 구현 결정은 아직 없다. 제안은 스캔으로 발견된 상호작용 대상에는 간결한 월드 표식을 표시하고, 조작 키 안내는 접근 및 타겟 조건을 만족할 때만 표시하는 방식이다.

## 현재 상태 및 이슈
- 사용자 디자인 선택과 실제 게임 화면에서의 크기·색상 검증이 남았다.
- 기존 `MarkerReaction`은 스프라이트 마커를 켜고 페이드하는 기능이며, 이름·키 안내 UI는 별도 설계가 필요하다.

## 다음 할 일
- 사용자가 표시 방식과 정보량을 선택하면, 실제 씬에서 위치·가독성을 확인하고 필요한 최소 UI 연결을 설계한다.
