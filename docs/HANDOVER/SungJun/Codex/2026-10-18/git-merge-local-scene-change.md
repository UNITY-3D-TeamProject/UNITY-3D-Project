# Git 병합 중 로컬 씬 변경 충돌 안내

## 작업 요약
- Git 오류 화면의 의미를 확인하고 안전한 해결 경로를 설명했다.

## 방법/접근
- 오류에 표시된 `UnityAssets/Scene/TestScene.unity`의 로컬 변경이 병합 결과로 덮어써질 수 있어 Git이 병합을 중단한 것으로 판단했다.
- 현재 작업 트리의 `git status`와 씬 파일 존재 여부를 확인했다.

## 변경된 파일
- 이 인수인계 기록과 `HANDOFF_POINTER.md`만 변경했다.

## 결정 사항
- 로컬 씬 변경의 보존 여부를 사용자가 판단하기 전에는 커밋, 스태시, 폐기를 실행하지 않는다.

## 현재 상태 및 이슈
- 현재 작업 트리에는 오류에 표시된 씬 경로가 없고, 해당 파일의 로컬 변경도 표시되지 않는다. 오류 화면과 현재 체크아웃 상태가 다를 수 있다.

## 다음 할 일
- 오류가 발생한 저장소와 체크아웃에서 `git status`를 확인하고, 씬 변경을 보존할지 결정한 뒤 커밋 또는 스태시하고 병합을 재시도한다.
