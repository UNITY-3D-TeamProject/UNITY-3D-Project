# 메인화면 커밋 범위

## 작업 요약 및 결정 사항
- 사용자 요청에 따라 정식 메인화면 변경을 하나의 로컬 커밋으로 묶는다.
- 메시지: feat: 로비 배경 기반 메인화면 및 카메라 전환 연출 추가
- 작업자 표기: KimSungJun(git config user.name).
- MainScene, 전환 스크립트, 로비 배경 프리팹, 대기 컨트롤러, 복원된 전용 시각 에셋과 meta, 관련 intent/handover 및 검증 이미지를 포함한다.
- 기존 ProjectSettings 및 전광판 RT 변경과 별도 Test 저장소는 포함하지 않는다. Push하지 않는다.

## 검증 및 현재 상태
- 이전 Play에서 검은 첫 화면, 페이드/카메라 이동, 메뉴 표시, 설정창/ESC 및 에셋 복구를 확인했다.
- 이번 커밋 단계에서 새 기능이나 게임 코드를 추가하지 않았다.
- 저장 데이터가 있을 때 START 확인 패널을 표시하는 요청은 아직 구현하지 않았다.
- 다음 작업자는 git log에서 생성된 커밋을 확인하고 필요시 START 확인 기능을 이어서 진행한다.
