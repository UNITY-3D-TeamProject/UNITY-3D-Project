# 스캔·보드 스킬 카드 아이콘 교체

## 작업 요약 및 방법
- 사용자가 제공한 첫 번째 그림을 Scan_Smile 투명 스프라이트로, 두 번째 그림을 Board_Skateboard 투명 스프라이트로 준비했다.
- Canvas_InGame의 스캔·기존 블루투스 카드 아이콘 참조를 교체하고 표시 이름 BLUETOOTH를 BOARD로 변경했다.
- 후속 요청으로 스캔·보드 아이콘 RectTransform을 각각 54×54에서 88×88로 키웠다. 원형 Disc는 96×96으로 유지했다.
- 기존 아이콘 색(밝은 청백색)을 유지했다. 사용자가 이 색상을 선택했다.

## 결정 사항
- 쿨타임 및 스킬 연결 코드는 변경하지 않았다. 내부 Bluetooth 식별자는 기존 SpawnVehicle 연결을 위해 유지한다.

## 현재 상태 및 이슈
- 두 이미지의 투명도, 256×256 크기, 프리팹의 GUID 참조, BOARD 글자와 git diff를 확인했다.
- 88×88에서 이미지의 실제 불투명 가로폭은 스캔 약 77, 보드 약 73으로 Disc 96 안에 들어간다.
- Unity Pipeline 서버에 연결되지 않아 실제 에디터 import 및 Play 화면은 확인하지 못했다.
