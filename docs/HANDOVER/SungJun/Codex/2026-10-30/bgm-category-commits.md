# BGM 변경을 종류별로 커밋

## 작업 요약 및 방법
- 씬 파일을 제외하고 BGM 공통 코드, 로비, 피드, 미로 변경을 기능별 커밋으로 나눴다.
- 작업 기록과 intent 변경은 문서 커밋으로 따로 묶는다.

## 결정 사항
- `Map_1_Lobby`, `Map_2_Feed`, `Map_3_File` 씬 변경은 스테이징하지 않는다.
- Unity가 생성한 폰트 아틀라스·렌더 텍스처 변화, VFX 메타 GUID 변화, 프로젝트 설정·솔루션 파일 및 `.codex` 설정은 BGM 작업과 무관해 제외한다.
- `Assets/ThirdParty/Audio/Bgm`의 WAV와 메타는 프로젝트 Git 무시 규칙에 따라 커밋하지 않는다.

## 현재 상태 및 이슈
- BGM SO는 로컬의 Git 무시 대상 WAV를 참조하므로, 다른 환경에서는 WAV와 메타를 별도로 공유해야 한다.
- 사용자 요청에 따라 Unity 재생·컴파일 검증은 수행하지 않았다.

## 다음 할 일
- 씬 변경을 별도 커밋할 때 BGM SO 참조와 WAV 전달 방식을 함께 확인한다.
