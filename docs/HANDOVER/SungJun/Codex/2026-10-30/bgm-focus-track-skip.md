# 에디터 포커스 복귀 시 BGM 곡 넘김 수정

## 작업 요약 및 방법
- `AudioManager.CoPlayTracks`의 대기 조건에서 `AudioSource.isPlaying` 검사를 제거했다.
- 포커스 이동으로 오디오가 일시정지되어도 남은 재생 시간이 페이드아웃 구간에 도달하기 전에는 다음 곡으로 넘어가지 않도록 했다.

## 결정 사항
- 플레이리스트의 자동 전환 시점은 `GetRemainingBgmTime()`으로 판단한다.

## 현재 상태 및 이슈
- Unity의 일시정지 중 `AudioSource.isPlaying`이 false가 될 수 있다는 API 문서와 기존 코드 조건을 근거로 수정했다.
- 사용자 요청에 따라 재생·컴파일 검증은 수행하지 않았다.

## 다음 할 일
- 필요할 때 에디터 포커스를 이동했다 돌아와 현재 곡이 유지되는지 확인한다.
