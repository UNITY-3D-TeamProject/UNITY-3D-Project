# 파일맵 장애물 소리 누락 진단

## 작업 요약 및 방법
- AudioManager의 단발음/반복음 요청 경로, 파일맵 생성 설정, 장애물 프리팹과 CycleTimer를 확인했다. 코드 수정 및 Play 청취 재현은 하지 않았다.

## 확인 사항
- PlaySfx와 PlayUi는 TryPickClip에서 클립별 마지막 요청 시각으로 0.05초 중복을 제한한다. 요청 위치나 청취자 거리는 비교하지 않는다.
- PlaySfxLoop는 이 제한을 거치지 않는다. 반복음 64개 상한은 별도 조건이다.
- 파일맵은 시작 시 장애물을 생성하며, 가시 등 동일 프리팹의 CycleTimer는 같은 주기와 startDelay 0을 사용한다. 같은 클립의 동시 요청 중 첫 요청만 남으므로, 먼 장애물이 먼저 요청하면 가까운 장애물 소리가 누락될 수 있다. 같은 박자로 반복되면 다음 주기에도 누락될 수 있다.

## 다음 할 일
- 실제 Play에서 먼 장애물과 가까운 장애물의 동시 요청을 계측하고 청취한다.
- 3D 단발음의 중복 제한을 소리 발생 위치별로 구분하는 수정 검토. UI 중복 제한과 반복음 처리는 별도로 유지한다.
- 기존 펫 수정 스테이징은 유지했으며 이 진단은 스테이징하지 않았다.
