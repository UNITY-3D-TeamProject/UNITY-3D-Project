# 튜토리얼 펫 방향 후속 확인

## 작업 요약 및 방법
- 기존 대사·독백·안내 문구와 관련 작업 기록 28개 파일을 검토해 `6f4d1bd2`로 커밋했다.
- `PetFollower`의 회전 기준, `Pet.prefab`의 모델 회전, 원본 Rob11 FBX의 얼굴 유리 부분 위치를 확인했다.
- Unity Pipeline에 연결 가능한 Editor가 없어 Play 재현은 수행하지 못했다.

## 결정 사항
- 펫 모델의 얼굴 유리 부분은 원본 모델 +Z 쪽에 있고, 추종 코드는 +Z를 이동 방향으로 회전시킨다. 모델 축을 임의로 180도 뒤집지 않았다.
- 사용자의 '뒤를 보고'가 이동 방향 반대를 뜻하는지, 뒤쪽 카메라에 등이 보인다는 뜻인지 확인 요청을 보냈다.

## 현재 상태 및 이슈
- 펫 방향 수정은 증상 구분에 필요한 사용자 답변을 기다리는 중이다.
- 폰트, ProjectSettings, 솔루션 파일, `.codex/config.toml`은 대사 커밋 범위에서 제외했다.

## 다음 할 일
- 사용자 답변에 따라 펫이 이동 방향을 바라보도록 모델/회전을 바로잡거나, 플레이어 시점에서 얼굴이 보이도록 원하는 배치·회전 정책을 정한 뒤 최소 수정한다.
- 가능하면 Unity Play에서 실제 이동 방향과 펫 얼굴 방향을 비교한다.
