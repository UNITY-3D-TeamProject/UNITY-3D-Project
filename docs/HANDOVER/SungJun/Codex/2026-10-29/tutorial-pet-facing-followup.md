# 튜토리얼 펫 방향 수정

## 작업 요약 및 방법
- 잘못 적용했던 펫 모델 회전 커밋 `798ec1b4`를 `git reset --mixed`로 내렸다. 이 작업은 커밋하지 않았다.
- Unity 6000.4.8f1에서 `Map_0_Tutorial`을 Play하고 `ResumeSpawnerCube`의 실제 상호작용으로 펫을 깨웠다.
- 기존 추종 코드가 펫이 피벗을 따라잡으려고 뒤로 이동할 때 그 방향으로 펫까지 돌리는 것을 확인했다.

## 결정 사항
- Rob11 모델 자식의 Y축 180도 회전은 앞뒤를 뒤집으므로 되돌렸다. 모델 앞면은 루트 기준 +Z다.
- `PetFollower`는 추종 속도와 관계없이 펫 피벗의 정면을 향하도록 바꿨다.
- 이 추종 코드는 튜토리얼뿐 아니라 다른 씬의 펫에도 적용된다.

## 검증 결과
- Unity 재컴파일 성공. 수정 후 같은 상호작용으로 Play했을 때 펫과 플레이어 모두 카메라에 등을 보이며 전방을 향했다.
- 펫 속도가 `(0, 0, -2.51)`로 뒤쪽을 향하는 순간에도 피벗·펫 루트·모델의 Y 회전이 모두 0도였다. 이동 방향 때문에 얼굴이 뒤집히지 않는다.
- Play를 종료하고 검증 전 열려 있던 `TestScene`으로 에디터를 복원했다. 캡처 파일은 제거했다.

## 현재 상태
- 이번 펫 수정과 작업 기록은 아직 커밋되지 않았다. 별도로 존재하던 사용자 변경 사항은 건드리지 않았다.
