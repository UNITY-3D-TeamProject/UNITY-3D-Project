# 스킬 배터리 소모량 UI 정정

## 작업 요약 및 방법
- `Canvas_InGame`의 스킬 카드 비용 텍스트를 실제 플레이어 설정에 맞춰 변경했다: 스캔 `5`, Roll(대쉬) `1`, 블루투스 `5/s`.
- 블루투스는 `Player.prefab`의 `SpawnVehicle` 인스턴스에서 초당 소모량 `5`로 오버라이드되어 있다.

## 결정 사항
- 지속 소모와 1회 소모를 구분하기 위해 블루투스 비용에는 `/s` 단위를 표시한다.

## 현재 상태 및 이슈
- 프리팹 텍스트만 수정했다. Unity 실행 및 화면 확인은 하지 않았다.

## 다음 할 일
- 사용자가 게임 화면에서 표시 크기와 가독성을 확인한다.
