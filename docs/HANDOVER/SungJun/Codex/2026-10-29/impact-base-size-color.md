# 명중 VFX 기본 크기 0.8배 및 색상 강화

## 작업 요약 및 결정
- 사용자가 근거리 명중 이펙트 크기를 기존의 0.8배로 줄이고 색을 진하게 요청했다.
- 최초에는 일반·차지 명중 SOEffectData의 Scale을 0.8로 설정했으나 사용자가 원한 것은 원본 파티클 자체 축소였다. 최종적으로 두 SO의 Scale은 1로 복원하고 파티클 시작 크기를 0.15~0.45→0.12~0.36, 시작 속도를 2~5→1.6~4, Shape.scale을 (0.28,0.28,0.08)→(0.224,0.224,0.064)로 줄였다. 런타임에 별도 0.8배를 곱하지 않는다.
- Bullet.prefab의 Hit Vfx Max Scale은 사용자 요청으로 3을 거쳐 3.5로 조정했다. ChargedBullet은 이를 상속한다. 카메라 거리 10m 이내 1배, 20m 2배, 30m 3배, 35m 이상 최대 3.5배를 작은 원본 파티클에 적용한다.
- 트레일과 공유하던 ThirdParty 머티리얼은 수정하지 않고 `_Project/Art/VFX/M_DataPacketImpact(.mat)` 및 Charged 전용 머티리얼을 복사 생성했다.
- 명중 전용 머티리얼의 Fill 0.14→0.32, EdgeWidth 0.048→0.065, Intensity 4.5→2.0으로 조정해 내부와 테두리를 또렷하게 하고 하얗게 날아가는 부분을 줄였다.
- 일반 파티클 시작색은 청록 (0.02,0.58,1)~보라 (0.45,0.03,1), 차지는 주황 (1,0.35,0.02)~노랑 (1,0.8,0.03)으로 채도를 높였다.

## 검증
- Unity 도구 스크립트 실행 성공, 컴파일 진단 없음.
- 최종 조정 후 별도 빈 씬 Play에서 일반·차지 BulletController.PlayHitVfx 경로를 5/10/20/30/35/60m로 호출해 실제 이펙트 루트 배율 1/1/2/3/3.5/3.5, 파티클 크기 0.12~0.36을 확인했다. 이전에 검증한 물리 충돌 자체는 이번에는 재검증하지 않았다.
- 초기 색상 비교 단계에서는 저장하지 않은 빈 씬 Play에서 실제 명중 SO를 EffectManager로 재생하고 rootScale=(0.8,0.8,0.8), 정상 셰이더 지원을 확인했다. 이후 원본 파티클 축소 요청에 따라 SO Scale=1로 복원하고 위 거리별 배율 검증을 다시 수행했다.
- 동일 seed 42, 동일 시점 0.12초로 이전 값과 새 값을 렌더해 일반·차지 각각 전후 화면 확인. 크기가 20% 줄고 색이 진하게 표현된다.
- Play 종료, TestScene 및 runInBackground=false 복원. 임시 도구·캡처 제거.
