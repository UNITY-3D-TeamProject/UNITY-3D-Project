# 2단계 PlayerState 라운드 스냅샷 코드 안내

- 작업 요약 및 방법: 사용자 요청에 따라 다음 단계의 적용 코드를 대화로 안내한다. PlayerState, AttributeSet/AttributeData, SOAttributeData_Player 및 코딩 컨벤션을 확인했다.
- 결정 사항: PlayerState 내부에 라운드 인덱스를 키로 사용하는 별도 Dictionary와 읽기 전용 체력·배터리 구조체를 추가하는 안이다. 같은 라운드가 이미 있으면 저장을 건너뛴다. 위치 매핑은 StageManager가 담당한다.
- 확인 결과: 능력치 키는 CurrentHp와 CurrentBattery다. GetValue/SetValue/IsValidTarget을 사용할 수 있고 SetValue는 능력치 변경 콜백을 발생시킨다. 기본 플레이어 SO의 두 현재값은 0이므로 초기화/씬 전환 복원 이후 저장해야 한다.
- 현재 상태 및 이슈: 런타임 파일은 수정하지 않았다. 제안 코드의 Unity 컴파일 및 실행 검증도 수행하지 않았다. 2단계를 구현 완료로 표시하지 않는다.
- 다음 할 일: 사용자가 코드 적용 후 확인을 요청하면 실제 변경을 검토한다. 이후 3단계 최초 스폰 위치/초기 스냅샷 연결, 4단계 도달 저장, 7단계 사망 복원에서 호출을 연결한다. 새 스테이지 시도 시 스냅샷을 비우고 같은 시도의 사망 재시도에서는 유지한다. 복원 중 사망/낙하 중복 방지는 후속 복구 단계에서 처리한다.
- 변경된 파일: 이 안내 기록과 HANDOFF_POINTER.md.
