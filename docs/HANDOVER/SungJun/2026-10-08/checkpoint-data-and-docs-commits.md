# 체크포인트 데이터와 문서 커밋 분리

- 작업자: 김성준
- 이름 표기 정정: 사용자가 요청한 김성준은 커밋 본문의 작업자 표기다. Git author/committer는 기존 설정 KimSungJun을 유지한다. 로컬 두 커밋의 작성자를 정정했으며, 푸시 승인 거절 이후 원격 전송은 재시도하지 않았다.
- 작업 요약: 사용자 요청으로 StageManager 데이터 구성 변경과 설계/인수인계 문서를 별도의 커밋 대상으로 정리했다.
- 방법: 실제 git diff와 커밋 컨벤션을 확인했다. 새 Markdown은 모두 docs/HANDOVER/SungJun 아래에 있으며, 기존 공용 intent 목차는 위치를 유지하고 문서 링크를 갱신한다.
- 코드 변경: 라운드별 체크포인트 인덱스 배열, 현재 라운드 인덱스, 라운드/체크포인트 읽기 전용 프로퍼티 추가. 기존 체크포인트 인덱스 선언 위치 변경과 미사용 낙하 처리 필드 제거가 사용자 변경에 포함돼 있다.
- 결정 사항: 동일 씬에서 기존 플레이어를 재사용하는 설계 유지. 1단계 데이터 코드가 실제 작업 트리에 반영됐으며 이후 기능은 아직 미구현이다.
- 검증: diff 및 필드 중복/참조 확인, git diff --check. Unity 컴파일·Play Mode 검증은 수행하지 않았다.
- 커밋 구성: feat: StageManager 라운드 체크포인트 데이터 구성 / chore: 플레이어 복구 설계 및 Codex 인수인계 문서 정리. 각 본문에 김성준과 상세 설명을 기록한다.
- 대상 브랜치: feature/System/DeathSystem. 원격 반영 결과는 Git 이력과 대화의 최종 보고에서 확인한다.
