# GameManager 목적별 선언 순서 정리

- 작업 요약: 사용자 요청에 따라 GameManager.cs의 변수·프로퍼티·이벤트와 함수를 목적별로 재배치했다.
- 방법: 원본 문자열에서 주석을 포함한 선언/함수 블록을 그대로 추출해 순서만 변경했다. 코드·주석·공백·인코딩은 보존했다.
- 배치: 상단 선언은 게임 상태 → 플레이어 생성/능력치 → 스테이지 참조/복귀 정보. 함수는 Unity 생명주기 → 게임 시작/일시정지/커서 → 생성 준비/완료 → 씬 전환/스테이지 처리.
- 검증: 모든 원본 블록을 정확히 한 번씩 사용하도록 순열 검사. 변경 전후 전체 문자 수와 모든 줄의 다중집합 동일 확인. 기존 초기화 값 사이의 의존성 없음 확인. 동작 변경이 없어 빌드/Play 검증은 재실행하지 않았다.
- git diff --check: 이동한 원본 OnEnable 블록의 기존 trailing whitespace 2줄을 지적한다. 사용자 요청에 따라 원문 그대로 보존했다.
- 현재 상태 및 다음 할 일: GameManager 정리 완료. 기존 체크포인트 Inspector 연결/Play 검증은 별도 후속 작업이다.
