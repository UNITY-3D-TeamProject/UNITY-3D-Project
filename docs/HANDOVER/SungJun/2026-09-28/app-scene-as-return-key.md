# 목적지 앱 씬 값으로 로비 복귀 위치 선택

- 작업 요약: 사용자가 목적지 앱 씬 값을 GameManager에 보관하고 로비 복귀 시 PlayerSpawner의 위치 선택에 사용하는 구조를 제시했다. 런타임 코드는 변경하지 않았다.
- 결정 사항: 앱마다 복귀 위치가 하나인 현재 논의에서는 목적지 앱 씬 값 자체를 복귀 위치의 키로 사용한다. 별도 지점 ID는 필요하지 않다.
- 방법/접근: 로비에서 앱 진입 시 GameManager에 해당 앱 씬 값을 기록한다. 로비로 돌아오는 전환에서는 저장한 앱 씬 값을 Lobby로 덮어쓰지 않는다. 로비 PlayerSpawner는 보관된 앱 씬 값에 대응하는 씬 내부 Transform을 선택하여 생성한다.
- 현재 상태 및 이슈: 설계 합의 단계이며 구현은 미착수. 최초 로비 진입은 기본 스폰 위치를 사용하고, 복귀 스폰 완료 후 저장값을 비우는 흐름을 제안했다.
- 다음 할 일: 구현 요청 시 전환 담당 이벤트와 앱 씬 값별 복귀 Transform 연결을 확인한다.
