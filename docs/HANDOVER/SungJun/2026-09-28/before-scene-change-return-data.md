# 씬 전환 직전 메서드의 복귀 정보 전달 논의

- 작업 요약: HandleBeforeSceneChange에 목적지 씬 정보가 필요한지 검토했다. 런타임 코드는 변경하지 않았다.
- 방법/접근: 현재 메서드는 능력치 저장만 수행하며 전환 이벤트 구독과 호출자는 연결되어 있지 않음을 확인했다.
- 제안 사항: 이 메서드에서 복귀 정보를 함께 관리한다면 전환 담당자가 목적지 씬과 선택적인 로비 복귀 지점 ID를 전달하도록 한다. 복귀 위치를 지정하는 핵심 정보는 입구 ID다. 로비에서 앱으로 진입할 때 ID를 보관하고, 앱에서 로비로 돌아올 때는 덮어쓰지 않고 유지하며 로비에서 스폰을 완료하면 소비한다. 능력치 저장만 맡긴다면 기존 무인자 메서드를 유지하고 앱 입구가 복귀 ID를 별도로 설정해도 된다.
- 현재 상태: 설계 설명 단계. 목적지 씬과 지점 ID는 서로 다른 정보이며, 앱에 입구가 여러 개라면 목적지 씬만으로 복귀 위치를 구분할 수 없다.
- 다음 할 일: 실제 전환 이벤트의 전달 데이터와 호출 순서를 확정한 후 연결한다.
