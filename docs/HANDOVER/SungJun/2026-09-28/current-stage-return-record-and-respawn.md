# 현재 스테이지 복귀 기록과 사망 재스폰 구분

- 작업 요약: 사용자가 목적지 enum 전달 없이 현재 씬의 스테이지 정보를 복귀 기록으로 보관하는 방향을 제시했다. GameManager와 PlayerSpawner를 재확인했다. 런타임 코드는 수정하지 않았다.
- 방법/접근: 전환 전 현재 씬 확인, 로비 여부에 따른 위치 선택, 로비에서만 기록을 소비하는 분기를 확인했다. 사망 관련 참조도 검색했다.
- 결정 사항: 현재 복귀 위치 용도에는 목적지 enum 전달이 필수적이지 않다. 씬 전환 담당자는 기존 씬을 내리기 전에 무인자 이벤트를 호출하고, GameManager는 능력치를 저장한 뒤 현재 씬이 스테이지일 때 SpawnStage를 갱신하는 흐름을 사용할 수 있다. 비스테이지 씬에서는 기록을 덮어쓰지 않는다.
- 현재 상태 및 이슈: PlayerSpawner는 선택한 spawnPoint.position/rotation을 실제 Instantiate에 적용하도록 수정되어 있다. 스테이지 스포너는 SpawnStage와 무관하게 자기 Transform을 사용하며 기록을 초기화하지 않는다. 로비 스포너만 기록으로 위치를 선택하고 생성·등록 후 ClearSpawnStage를 호출한다. 사망 후 같은 씬에서 재생성하는 호출 경로는 현재 PlayerSpawner에 없고 생성은 Start에만 있다.
- 다음 할 일: 현재 씬 이름→EStageType 판정과 실제 전환 전 이벤트를 연결한다. 같은 씬을 유지하는 사망 재스폰이 필요하면 재생성 호출 경로를 별도로 구현한다. 코드 정적 확인만 수행했고 Unity 실행 검증은 하지 않았다.
