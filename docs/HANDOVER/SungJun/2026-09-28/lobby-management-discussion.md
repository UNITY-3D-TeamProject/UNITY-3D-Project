# 로비 관리 책임 논의

- 작업 요약: StageManager, StageBase, EStageType, GameManager를 확인하고 로비 관리 방식을 검토했다. 런타임 코드는 변경하지 않았다.
- 방법: 사용자가 설명한 후반부의 소규모 상호작용을 기준으로 최소 구조를 제안했다. 첨부 PDF는 텍스트가 추출되지 않아 기획서 세부 내용은 판단 근거로 사용하지 않았다.
- 제안 사항: StageManager는 스테이지 진행과 클리어 상태를 담당하고, 단순한 로비 상호작용은 각 오브젝트가 처리한다. 여러 오브젝트를 클리어 상태에 따라 함께 변경하거나 엔딩 순서를 제어할 때만 씬 내부 LobbyController를 둔다.
- 현재 상태: 설계 제안이며 사용자 확정 전이다. OnAllStagesCompleted는 선언만 있고 현재 코드에는 호출이 없으므로 연결 시 완료 판정 구현이 필요하다.
- 다음 할 일: 로비의 구체적인 상호작용과 엔딩 조건을 확정한 뒤 필요한 범위만 구현한다.
