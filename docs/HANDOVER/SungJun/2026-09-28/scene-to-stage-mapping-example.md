# 전달받은 씬 enum의 스테이지 매핑 예시

- 작업 요약: 전달받은 ESceneType 값을 확인하여 대응하는 EStageType을 지정하는 의미를 설명하고 switch 예시를 안내했다. 런타임 코드는 수정하지 않았다.
- 방법/접근: 코딩 컨벤션을 확인하고 GameManager의 HandleBeforeSceneChange 내부에서 목적지별로 SpawnStage를 대입하는 최소 예시를 제시했다.
- 결정 사항: 서로 다른 enum을 직접 비교하거나 숫자 순서에 의존하는 캐스팅 대신 ESceneType의 항목을 분기 조건으로 사용하고 대응하는 EStageType을 명시한다.
- 현재 상태 및 이슈: ESceneType과 그 항목은 아직 제안 단계이며 예시는 실제 공용 enum이 정의된 후 사용할 수 있다. 로비 등 비스테이지 목적지는 SpawnStage를 변경하지 않아 앱 복귀 기록을 유지한다. 예시는 컴파일·실행 검증하지 않았다.
- 다음 할 일: 실제 씬 enum 항목이 확정되면 스테이지 목적지 다섯 개에 대한 매핑을 작성하고 씬 전환 이벤트에 연결한다.
