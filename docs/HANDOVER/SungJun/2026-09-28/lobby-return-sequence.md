# 목적지 앱 씬 저장 방식의 실행 순서

- 작업 요약: 사용자의 요청에 따라 앱 진입부터 로비 복귀 스폰까지 제안 흐름의 순서를 정리했다. 런타임 코드는 변경하지 않았다.
- 결정 사항: 로비에서 앱으로 이동하는 전환 요청의 목적지 앱 씬 값을 GameManager가 보관한다. 로비행 전환에서는 그 값을 유지한다.
- 방법/접근: 앱 진입 요청 → 전환 직전 목적지 앱 씬 기록 및 능력치 저장 → 앱 씬 로드 → 로비 복귀 요청 및 능력치 저장(앱 씬 기록 유지) → 로비 로드 → 스포너가 기록 조회 → 대응 위치와 방향에서 생성 → 복귀 기록 비우기 순서다. 최초 로비 진입은 기록이 없으므로 기본 위치를 사용한다.
- 현재 상태 및 이슈: 현재 HandleBeforeSceneChange는 무인자이고 이벤트 연결도 미구현이다. 이 기록의 순서는 구현할 설계 흐름이며 현재 실행 동작을 뜻하지 않는다.
- 다음 할 일: 구현 요청 시 전환 이벤트와 스포너에 최소 변경으로 연결한다.
