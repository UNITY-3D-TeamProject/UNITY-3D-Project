# 스테이지 사망 후 재스폰 위치 확인

- 작업 요약: SpawnPlayer를 재호출하면 스테이지의 원래 위치로 돌아갈 수 있는지 설명했다. 런타임 코드는 수정하지 않았다.
- 방법/접근: 직전에 확인한 PlayerSpawner의 위치 선택 분기를 근거로 설명했다. _isLobbySpawner가 false이면 spawnPoint는 스포너 자신의 transform이며 해당 position/rotation으로 Instantiate한다.
- 결정 사항: 원래 위치가 스테이지의 PlayerSpawner 위치를 뜻한다면 사망 후 같은 생성 함수를 재호출하여 그곳에 새 플레이어를 생성할 수 있다. 기존 플레이어 제거 후 생성하는 호출 흐름이 필요하다.
- 현재 상태 및 이슈: 현재 Start 본문 추출과 사망 처리 연결은 안내 단계이며 미구현이다. 기존 플레이어 이동이 아니라 새 인스턴스 생성 방식으로 설명했다. 컴파일·실행 검증은 하지 않았다.
- 다음 할 일: Start 본문을 SpawnPlayer로 분리하고 사망 처리에서 기존 플레이어 제거 후 호출한다.
