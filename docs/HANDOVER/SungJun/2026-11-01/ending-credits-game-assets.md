# 엔딩 크레딧에 게임 사용 에셋 목록 추가

## 1. 작업 요약 및 방법
- `Map_5_Live` `CreditsRoll`의 `m_text`만 YAML로 수정(씬 안 엶, 사용자가 엔딩 크레딧 수정을 직접 요청).
- `ASSETS & SOURCES` 아래, 기존 "컷신 제작 및 사용 에셋" 바로 앞에 "게임 제작 및 사용 에셋" 묶음 추가 (사용자가 준 THIRD-PARTY ASSETS 목록 + Mixamo — Adobe).
  - 형식은 컷신 묶음에 맞춤: 제목(32) → 부제(24 회색, "튜토리얼 · 로비 · 앱 스테이지 · 엔딩") → 카테고리(28 회색) → 항목(26).
  - 카테고리: 3D 아트 · UI / 시각 효과 / 캐릭터 애니메이션(Mixamo — Adobe) / 음악 · 효과음(효과음 7개 + "음악: Suno AI로 제작") / 폰트(Pretendard, Aldrich).
- "자세한 라이선스 및 저작권 고지: Third-Party Notices"(24 회색)는 두 묶음 모두에 해당하므로 컷신 묶음 뒤, SPECIAL THANKS 앞에 둠.
- 다시 쓴 텍스트는 원본과 같은 인코딩(`\uXXXX` 대문자)으로, 원본 그대로 다시 쓰면 같은지 먼저 확인한 뒤 수정. diff는 `m_text` 한 줄.

## 2. 결정 사항
- 게임 묶음 항목은 출처 설명 없이 에셋 이름만 (받은 목록 그대로). 컷신 묶음은 기존처럼 설명 + "출처:" 줄 유지.

## 3. 현재 상태 및 이슈
- 실제 엔딩에서 표시 미확인 (줄바꿈·글꼴 글리프·스크롤 길이). 명단이 약 60줄 늘어 스크롤 속도 80 기준 크레딧이 대략 20초 이상 길어진다 (2배속 가능).
- 커밋 안 함.
