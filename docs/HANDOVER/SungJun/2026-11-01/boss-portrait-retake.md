# 보스 체력 UI 거대보스(보스A) 초상화 다시 찍기

## 1. 작업 요약 및 방법
- 문제: 보스 체력 UI 초상화 `Art/UI/BossPortraits/BossA_Front.png` 는 2026-10-30 `57935ac4` 에서 찍었는데, 같은 날 `e4ed2747` 에서 보스A 모델이 Virus_King_Boss 로 바뀌어 예전 머리(빨간 눈 띠 사각형)가 남아 있었다.
- 원래 사진과 같은 구도로 지금 모델을 다시 찍어 같은 파일에 덮어썼다(`.meta`·GUID 유지, `Canvas_InGame` 연결 수정 없음).
  - TestScene Play 에서 `BossA.prefab` 을 빈 공간(y=-3000)에 회전 없이 만들고, `SetDamageMode(All)` 로 실드를 끈 채 촬영.
  - 정면(+Z 쪽에서 -Z 를 봄), 카메라 거리 40m(몸 앞면 z=10 기준), 세로 범위 9.8m(FOV 약 14°), 조준 높이 y=19.04 → 머리 블록이 가로를 거의 채우고 빨간 눈 띠가 가운데보다 조금 위(약 245px).
  - 512×512, 배경 투명(SolidColor 알파 0, 원래 파일과 같음).
- 얼굴을 더 꽉 채운 촬영본(세로 범위 5.6m)도 만들어 봤으나, 사용자가 위 구도(9.8m)를 골라 그대로 쓴다.
- 비교 확인: `Canvas_InGame` 을 저장 없이 불러와(`LoadPrefabContents` → `UnloadPrefabContents`) 체력 UI 를 예전/새 초상화로 각각 렌더: [비교 사진](./images/boss-portrait-compare.png)

## 2. 결정 사항
- 초상화는 원래 방식대로 정적 Sprite 를 쓰고 파일만 교체한다.

## 3. 현재 상태 및 이슈
- 비교 사진은 프리팹 기본 상태라 위쪽 큰 바가 B, 아래쪽 작은 바가 A 로 보이고 이름 칸도 프리팹 기본 문구다. 실제 보스전에서 A 가 큰 바로 보일 때의 모습은 확인하지 않았다.
