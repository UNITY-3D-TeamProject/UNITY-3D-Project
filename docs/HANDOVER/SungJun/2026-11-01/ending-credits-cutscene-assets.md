# 엔딩 크레딧에 컷신 에셋 출처 추가 (2026-11-01)

## 1. 작업 요약 및 방법
- 사용자가 준 "컷신 제작 및 사용 에셋" 목록(오프닝 · 피드 앱 · 파일 앱 · 엔딩 공연)을 엔딩 크레딧 `ASSETS & SOURCES` 아래 `...` 자리에 넣었다.
- 명단은 `Map_5_Live`의 `CreditsRoll` TextMeshProUGUI 하나(`m_text`)라서, 씬을 에디터로 열지 않고 YAML의 `m_text` 값만 바꿨다 (한글은 기존처럼 `\uXXXX` 이스케이프).
- 서식
  - 소제목 `컷신 제작 및 사용 에셋`(32) + 범위 `오프닝 · 피드 앱 · ...`(24, 회색 `#9AA4B8`)
  - 분류 제목 4개(캐릭터 · 배경 · 소품 / 캐릭터 애니메이션 / 음악 · 효과음 / 컷신 자체 제작 에셋)는 28, 회색
  - 항목마다 설명 줄(24, 밝은 회색 `#C8CEDA`) + `출처:`/`제작:` 줄(26, 흰색)
- 장식선(━)은 넣지 않았다.

## 2. 결정 사항
- 출처 줄 크기 26: 명단 폭 800px에서 가장 긴 줄(`MC Sample - Believable 3D Animations — Mocap Central`)이 28이면 약 796px로 폭에 닿아, 26(약 740px)으로 줄였다 (Pretendard-SemiBold 글꼴 폭으로 계산).
- `·`, `—`, `〈〉`는 Pretendard-SemiBold.otf에 있고 SDF 에셋이 동적 아틀라스라 실행 중 추가된다.
- `SPECIAL THANKS`의 `...`는 그대로 둠.

## 3. 현재 상태 및 이슈
- 씬 텍스트 값만 확인(디코딩해서 내용·순서 확인). 실제 엔딩 화면에서 줄바꿈·간격은 미확인.
- 명단이 길어져 스크롤 시간이 늘었다 (속도 80px/초 그대로). 노래 길이 안에 끝나는지 미확인.
- 커밋 안 함.

## 4. 다음 할 일
- 실제 엔딩에서 크레딧 확인(줄바꿈, 간격, 노래가 끝나기 전에 명단이 다 올라가는지). 길면 `_scrollSpeed`를 올린다.
- `SPECIAL THANKS` 내용 채우기.
