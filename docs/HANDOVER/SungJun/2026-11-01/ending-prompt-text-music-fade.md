# 엔딩 안내 문구 변경 + 크레딧 끝 노래 페이드아웃

## 1. 작업 요약 및 방법
- `Map_5_Live` 안내 문구 2개를 씬 파일의 `m_text` 두 줄만 직접 고쳐 변경(씬은 에디터로 열지 않음):
  - 영상 스킵 `Canvas_EndingCredits/VideoSkipPrompt`: "E 꾹 누르기 / 건너뛰기" → "E 꾹 눌러서 / 건너뛰기" (두 줄 배치 그대로)
  - 크레딧 2배속 안내(`EndingCredits._fastForwardHint`): "E 누르고 있기 : 2배속" → "E 꾹 눌러서 2배속 보기"
- `EndingCredits.CoFadeOut`: 끝에서 화면이 검게 덮이는 2초(`_fadeOutSeconds`) 동안 크레딧 노래 볼륨도 1 → 0으로 줄이고 마지막에 멈춤. 덮개가 연결 안 된 경우에도 노래는 줄어들도록 앞의 `yield break` 제거.

## 2. 결정 사항
- 노래 페이드아웃 시간은 화면 페이드아웃과 같은 값을 공유한다(따로 필드 만들지 않음).
- 로딩 씬(`Loading.unity`) 컷씬 스킵 안내(`VideoSkipPrompt/SkipLabel`, 폰 주인·피드 앱 뒤·파일 앱 뒤 영상 때 표시)도 사용자 요청으로 같은 "E 꾹 눌러서 / 건너뛰기"로 맞춤 (`m_text` 한 줄).

## 3. 현재 상태 및 이슈
- 리컴파일 통과. 실제 엔딩에서 문구 모양·노래 페이드 청취는 미확인. 커밋 안 함.

## 4. 다음 할 일 (Next Steps)
