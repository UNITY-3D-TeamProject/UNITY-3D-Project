# 커밋 메시지 AI 작성자 표시 제거

## 작업 요약 및 방법
- 사용자는 앞으로 커밋 메시지에 AI 공동 작성자 표시를 넣지 않도록 요청했다.
- `.agents/skills/commit/SKILL.md`의 자동 추가 지시를 제거하고 AI 작성자 표시 줄을 넣지 않는 규칙으로 교체했다.
- `.agent`와 `.claude`의 commit 스킬은 이미 같은 금지 규칙을 사용 중임을 확인했다.

## 결정 사항
- 커밋 메시지 제안과 실제 커밋 모두에 AI 작성자 표시를 자동으로 추가하지 않는다.

## 현재 상태 및 이슈
- 변경된 스킬의 규칙을 다시 읽어 적용을 확인했다.
- 자동 검증 스크립트는 `python` 명령이 없어 실행하지 못했다. 변경은 기존 Markdown 지시 한 항목으로 한정된다.
- 커밋과 푸시는 수행하지 않았다.
