# 폰 주인 노래 컷씬 구현 방식 검토

## 작업 요약
- 별도 씬 없이 현재 씬에서 동영상 컷씬을 표시할 수 있는 방법을 검토했다.
- 같은 스테이지에서 3D 캐릭터 연출을 실시간으로 재생하는 방식도 검토했다.

## 방법/접근
- 프로젝트의 Unity 버전, 씬 전환 구조, UI 및 패키지 구성을 확인했다.
- Unity 공식 문서에서 Video Player의 UI 표시 방식과 Timeline 용도를 확인했다.
- Unity Recorder로 에디터에서 3D 연출을 영상으로 녹화할 수 있음을 확인했다.

## 변경된 파일
- SungJun 폴더의 이 작업 기록과 HANDOFF_POINTER.md만 변경했다. 게임 코드와 에셋은 수정하지 않았다.

## 결정 사항
- 구현 방식은 아직 확정하지 않았다. 사전 제작 영상이면 Video Player와 UI Raw Image, 실시간 3D 연출이면 Timeline과 Cinemachine이 적합하다.
- 현재 프로젝트에는 Timeline과 Cinemachine이 설치되어 있고 Recorder는 설치되어 있지 않다.
- 고정된 노래 컷씬의 연출 일관성을 우선한다면 사전 제작 영상을 권장한다. 실제 재생 안정성은 대상 플랫폼의 코덱 호환성과 사전 준비, 빌드 테스트에 달려 있다.

## 현재 상태 및 이슈
- 영상 파일의 존재 여부와 연출 형태가 정해지지 않았다.
- GameManager.PauseGame은 Time.timeScale을 0으로 설정하므로 컷씬 재생 시 VideoPlayer 시간 업데이트 방식을 고려해야 한다.

## 다음 할 일
- 사용자가 영상 재생 방식을 최종 선택하고 원본 연출 또는 영상 파일을 준비하면 구현 범위를 확정한다.
