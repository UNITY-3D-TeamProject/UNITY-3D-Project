# Sehoon — Handover Pointer

이 파일은 Sehoon 명의로 진행한 작업 이력의 목차이다.
새 세션을 시작할 때 이 파일을 먼저 읽고 최신 항목부터 맥락을 파악한다.
작업을 마무리할 때는 오늘 날짜 폴더에 새 문서를 만들고, 아래 목록 맨 위에 한 줄 항목을 추가한다.
