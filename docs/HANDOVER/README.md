# Handover 시스템

이전에 쓰던 루트의 `MEMORY.md`(단일 파일)를 대체하는, 참여자별 인수인계 기록 시스템이다.
사람이든 AI 에이전트든, 이름으로 자신의 폴더를 갖고 그 안에 날짜별 작업 기록을 남긴다.

## 폴더 구조
```
docs/HANDOVER/
  {이름}/
    HANDOFF_POINTER.md      <- 그 사람의 작업 이력 목차 (최신순)
    {YYYY-MM-DD}/
      {제목}.md              <- 실제 작업 기록 문서
  _template/                 <- 새 참여자 폴더를 만들 때 복사하는 템플릿
    HANDOFF_POINTER.md
```

## 이름 기준
`{이름}`은 실제 참여자의 이름/닉네임이다 (예: `Minsung`). 한 사람이 다른 AI 도구를 함께 쓰더라도 폴더는 사람 기준으로 하나만 둔다.

## HANDOFF_POINTER.md 규칙
- 파일 맨 위에 **변경 이력을 최신순으로** 나열한다. 각 항목은 날짜 + 한 줄 요약 + 해당 날짜 문서로의 링크로 구성한다.
  ```
  ## 변경 이력 (최신순)
  - **YYYY-MM-DD** — 한 줄 요약: [문서 제목](./YYYY-MM-DD/파일명.md)
  ```
- 새 작업을 끝낼 때마다 이 목록 맨 위에 새 항목을 추가한다. 기존 항목은 지우지 않는다.
- 목록이 아주 길어지면(예: 수십 개) 오래된 항목은 그대로 두되, 맨 위에 "현재 상태 요약" 섹션을 두어 최신 맥락만 빠르게 파악할 수 있게 해도 된다.

## 날짜별 작업 문서 ({YYYY-MM-DD}/{제목}.md) 작성 항목
1. **작업 요약**: 무엇을 했는지
2. **방법/접근**: 어떻게 했는지 (선택한 방식과 이유)
3. **변경된 파일**: 주요 파일 목록
4. **결정 사항**: 채택된 규칙/구조가 있다면
5. **현재 상태 및 이슈**: 미해결 문제
6. **다음 할 일**: 이어받을 사람이 참고할 내용

## AI 에이전트 사용 지침
- 새 세션을 시작할 때, 자신에게 해당하는 (또는 사용자가 지정한) `docs/HANDOVER/{이름}/HANDOFF_POINTER.md`를 먼저 읽고 최신 항목들로 맥락을 파악한다. 해당 폴더가 없으면 `_template/`을 복사해 새로 만든다.
- 작업(대화)을 마무리하기 전, 오늘 날짜 폴더에 작업 기록 문서를 새로 작성하고 `HANDOFF_POINTER.md` 맨 위에 항목을 추가한다.
- 같은 날 같은 사람이 여러 번 세션을 진행하면, 같은 날짜 폴더 안에 문서를 더 추가하거나(제목 구분) 기존 문서를 갱신한다.
