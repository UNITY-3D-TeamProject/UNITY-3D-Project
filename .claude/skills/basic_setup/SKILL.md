# Unity 기본 규칙 스킬 (Basic Setup Skill)

이 스킬은 AI가 유니티 코드를 생성하거나 수정할 때 참고해야 할 필수 뼈대 규칙을 담고 있습니다.

1. **폴더 위치 확인**: 모든 C# 스크립트는 `Assets/_Project/Scripts/` 하위에 적절한 모듈 폴더를 생성하여 배치해야 합니다.
2. **명명 규칙**: 클래스명은 PascalCase, 프라이빗 변수는 _camelCase를 사용합니다.
3. **메모리 업데이트**: 작업이 끝나면 항상 프로젝트 루트의 `MEMORY.md` 파일을 업데이트하여 다음 작업을 준비하세요.
